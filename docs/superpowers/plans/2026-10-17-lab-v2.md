**Goal:** Turn `/lab` into a narrative-first page (round digest → observer note → storylines → metrics) backed by deterministic per-round reads, keep today's lab verbatim at `/lab/v1`, and add a machine-written, labelled observer note per round.

## Spec rulings (binding; read before Task 1)

1. **`outcomes.timeouts` → `outcomes.missing`.** A timed-out worker is killed and files no `cycle_run` card, so no stored row records a timeout. The digest reports `missing` = arm size − cards on a sweep round (the same definition as the reliability block), `0` on a manual round. It also reports `deviations` (model-mismatch cards), since the spec says those are "listed".
2. **`changes.dreams` carries drift, not a 最近 diff.** Era 3 dream snapshots store `excerpt` = the first 280 code points of card + 最近 (a card is up to 600 code points, so 最近 is almost always cut off) and no `diffNarrative`. No stored row holds the before/after 最近 list. Each entry is `{ username, arm, capturedAt, driftFromAnchor, driftFromPrev }` from the round's dream snapshots; a dream without a snapshot is omitted (spec: "omitted, not invented"). Filing 最近 into snapshots is out of scope. **Amended by Task 15:** the dream success event files `recentBefore`/`recentAfter`, and the digest adds an optional `recent` diff.
3. **Post links go to `/p/:id`**, the real route (`App.tsx`), not `/post/:id`.
4. **`newWords` is as-of the round.** A token is listed for sweep round R if, using only utterances up to R's `endedAt` and sweeps up to R, it meets the amendment's adoption rule (≥ 2 other accounts, strictly later round) and ≥ 1 adopter first used it in R; `adopters` lists those R adopters. A closed round's list therefore does not change when later rounds add adopters (so old notes do not go stale for that reason). Manual rounds have none. At most 10.
5. **Digest post set = the round's post vectors whose post is `active` and `public`** (lab reads are public). `conv` and `mostAlike` are computed over that set in-process with `arms/metrics.ts` `cosine`; vectors never leave the server. `conversations` likewise only on public active posts, active comments. `interactions` counts like homophily (any status), restricted to the window.
6. **Highlights never overlap:** `mostInCharacter` = the top `min(3, ceil(n/2))` by `cardSim`, `leastInCharacter` = the bottom `min(3, rest)` of the remainder, ascending; deviation posts and null `cardSim` excluded. `mostAlike` = top 3 cross-account pairs, deviation posts excluded. `conversations` = posts with ≥ 2 distinct roster commenters in the window; `participants` = those commenters plus the post's author when on the roster; top 5 by comment count.
7. **Numbers in the digest are rounded to 4 decimals** before hashing, so `digestHash` (sha256 of canonical, key-sorted JSON of everything except `digestHash` and `observation`) is stable.
8. **The observation is not cached with the digest.** `GET /agents/rounds/:roundId` reads the one `round_observations` row per request, so a `PUT` shows at once; the `PUT` clears the 60 s list cache so `hasObservation` updates too.
9. **v2.0 contract has no `hasObservation` / `observation`;** v2.1 adds both (the table does not exist before 0007).
10. **The `PUT` 404s for an unknown round and 400s for a malformed one** (same checks as the GET, after the token check). It always answers 200 `{ roundId, updatedAt }`.
11. **The `PUT` body is a lab contract schema (`contract/lab/rounds.ts`), not an `…Ingest` body**: it is not an account ingest (no API key, no username), so it does not join `INGEST_BODIES` / the agent's generated JSON Schemas. The agent test pins the exact body instead.
12. **Storylines reuse `era3/ArmRoster` and `era3/Era3AgentDetail` as-is** — the latter already reads `/agents/:u/rounds` and the drift snapshots (per-round `card_sim`, convergence, 最近/snapshot history). Writing a new `AccountStory` would duplicate it.
13. **Default round** = newest sweep round in the list, else newest round of any kind. **Next-round ETA** = newest sweep `startedAt` + 48 h (the round script's default `ROUND_MIN_INTERVAL_HOURS`); past it the strip says "due".
14. **`OBSERVE` joins the caller variables that outrank `agent/.env` inside the round** (nine, was eight), so `OBSERVE=0 bash agent/scripts/opportunistic-round.sh --force` works.
15. **`swil-agent observe` exit codes:** 0 written (or printed with `--dry-run`), 64 malformed id / server 400, 66 no such round, 75 token unset, server/model down, empty reply, or a refused PUT. The user turn is the digest JSON without any `observation` key (a note never reads the previous note).
16. **API doc file is `docs/03-api-reference.md`** (the spec says `03-api.md`).

Replace `loadInteractionEdges` with:

```ts
/**
 * Every roster → roster interaction, grouped per (source, target, kind) in
 * the database: five bounded queries whatever the corpus size. With a window,
 * only interactions whose own timestamp (the comment's, the like's, the echo
 * post's, the follow's) falls inside it, ends included. Without one the edges
 * are exactly the arms report's.
 */
export async function loadInteractionEdges(
  roster: readonly RosterUser[],
  window?: TimeWindow,
): Promise<KindedEdge[]> {
  const ids = roster.map((u) => u.id);
  if (ids.length === 0) return [];
  const n = count();
  const inWindow = (col: AnyPgColumn) => (window ? between(col, window.from, window.to) : undefined);
  const tag =
    (kind: InteractionKind) =>
    (rows: InteractionEdge[]): KindedEdge[] =>
      rows.map((r) => ({ ...r, kind }));

  const groups = await Promise.all([
    // comment → the commented post's author
    db
      .select({ source: comments.authorId, target: posts.authorId, n })
      .from(comments)
      .innerJoin(posts, eq(comments.postId, posts.id))
      .where(
        and(
          inArray(comments.authorId, ids),
          inArray(posts.authorId, ids),
          ne(comments.authorId, posts.authorId),
          inWindow(comments.createdAt),
        ),
      )
      .groupBy(comments.authorId, posts.authorId)
      .then(tag('comment')),
    // like on a post → its author
    db
      .select({ source: likes.userId, target: likedPosts.authorId, n })
      .from(likes)
      .innerJoin(likedPosts, and(eq(likes.targetType, 'post'), eq(likes.targetId, likedPosts.id)))
      .where(
        and(
          inArray(likes.userId, ids),
          inArray(likedPosts.authorId, ids),
          ne(likes.userId, likedPosts.authorId),
          inWindow(likes.createdAt),
        ),
      )
      .groupBy(likes.userId, likedPosts.authorId)
      .then(tag('like')),
    // like on a comment → its author
    db
      .select({ source: likes.userId, target: likedComments.authorId, n })
      .from(likes)
      .innerJoin(
        likedComments,
        and(eq(likes.targetType, 'comment'), eq(likes.targetId, likedComments.id)),
      )
      .where(
        and(
          inArray(likes.userId, ids),
          inArray(likedComments.authorId, ids),
          ne(likes.userId, likedComments.authorId),
          inWindow(likes.createdAt),
        ),
      )
      .groupBy(likes.userId, likedComments.authorId)
      .then(tag('like')),
    // echo → the original post's author
    db
      .select({ source: posts.authorId, target: origPosts.authorId, n })
      .from(posts)
      .innerJoin(origPosts, eq(posts.echoOf, origPosts.id))
      .where(
        and(
          inArray(posts.authorId, ids),
          inArray(origPosts.authorId, ids),
          ne(posts.authorId, origPosts.authorId),
          inWindow(posts.createdAt),
        ),
      )
      .groupBy(posts.authorId, origPosts.authorId)
      .then(tag('echo')),
    // follow → followee
    db
      .select({ source: follows.followerId, target: follows.followingId, n })
      .from(follows)
      .where(
        and(
          inArray(follows.followerId, ids),
          inArray(follows.followingId, ids),
          ne(follows.followerId, follows.followingId),
          inWindow(follows.createdAt),
        ),
      )
      .groupBy(follows.followerId, follows.followingId)
      .then(tag('follow')),
  ]);
  return groups.flat();
}
```

```ts
    .sort((a, b) => a - b);
  // Before the 3rd sweep starts, every token is baseline (< 3 sweeps: all of them).
  const cutoff = starts.length > BASELINE_SWEEPS ? starts[BASELINE_SWEEPS] : Infinity;
  // Same-timestamp utterances are ordered by id, so the origin of a token
  // first used twice in one instant is deterministic. It cannot change whether
  // the token is adopted: both uses fall in the same sweep round, and adoption
  // only counts other accounts' first use in a strictly later round.
  const ordered = utterances
    .filter((u) => byId.has(u.userId))
    .sort((a, b) => a.createdAt.getTime() - b.createdAt.getTime() || a.id.localeCompare(b.id));

  const early = new Set<string>();
  const spreads = new Map<string, Spread>();
  ordered.forEach((u, order) => {
    const t = u.createdAt.getTime();
    const tokens = tokenize(u.text);
    if (t < cutoff) {
      for (const tok of tokens) early.add(tok);
      return;
    }
    const round = roundIndex(starts, t);
    for (const tok of tokens) {
      if (early.has(tok) || era2.has(hashToken(tok))) continue;
      const s = spreads.get(tok);
      if (!s) {
        spreads.set(tok, {
          token: tok,
          origin: u.userId,
          originRound: round,
          originOrder: order,
          firstRound: new Map([[u.userId, round]]),
        });
      } else if (!s.firstRound.has(u.userId)) {
        s.firstRound.set(u.userId, round);
      }
    }
  });
  return { spreads, starts };
}

/** Other accounts whose first use is in a strictly later sweep round than the origin's. */
function adoptersOf(s: Spread): string[] {
  return [...s.firstRound]
    .filter(([user, round]) => user !== s.origin && round > s.originRound)
    .map(([user]) => user);
}

/** Pure core: rounds, roster utterances (any order) and the Era 2 token hashes. */
export function buildContagion(
  state: RoundsState,
  utterances: readonly Utterance[],
  era2: ReadonlySet<number>,
): Contagion {
  const byId = new Map(state.roster.map((u) => [u.id, u]));
  const { spreads } = collectSpreads(state, utterances, era2);

  const counts = new Map(ARMS.map((a) => [a.id, { innovations: 0, adopted: 0 }]));
  const adopted: { spread: Spread; adopters: string[] }[] = [];
  for (const s of spreads.values()) {
    const arm = (byId.get(s.origin) as { arm: ArmId }).arm;
    const c = counts.get(arm) as { innovations: number; adopted: number };
    c.innovations += 1;
    const adopters = adoptersOf(s);
    if (adopters.length < MIN_ADOPTERS) continue;
    c.adopted += 1;
    adopted.push({ spread: s, adopters });
  }

  adopted.sort(
    (a, b) =>
      b.adopters.length - a.adopters.length ||
      a.spread.originOrder - b.spread.originOrder ||
      (a.spread.token < b.spread.token ? -1 : a.spread.token > b.spread.token ? 1 : 0),
  );

  return {
    status: state.completedRounds >= CONTAGION_MIN_COMPLETED ? 'ok' : 'collecting',
    arms: ARMS.map((a) => {
      const { innovations, adopted: n } = counts.get(a.id) as {
        innovations: number;
        adopted: number;
      };
      return { arm: a.id, innovations, adopted: n, rate: innovations ? n / innovations : null };
    }),
    top: adopted.slice(0, TOP_LIMIT).map(({ spread, adopters }) => {
      const origin = byId.get(spread.origin) as { username: string; arm: ArmId };
      return {
        token: spread.token,
        origin: origin.username,
        originArm: origin.arm,
        adopters: adopters.length,
        adopterArms: [
          ...new Set(adopters.map((id) => (byId.get(id) as { arm: ArmId }).arm)),
        ].sort(),
      };
    }),
  };
}

/** New words a round digest lists, at most. */
export const ROUND_ADOPTIONS_LIMIT = 10;

/** One token adopted as of a round: its origin and the adopters whose first use is in that round. */
export interface RoundAdoption {
  token: string;
  origin: string;
  adopters: string[];
}

/**
 * Tokens adopted (the amendment's rule) as of the END of sweep round
 * `roundId`, with ≥ 1 adopter whose first use falls in that round. As-of:
 * only utterances up to `endedAt` and sweeps up to this one count, so a closed
 * round's list does not move when later rounds add adopters. Manual and
 * unknown rounds have none: contagion is defined over sweep rounds.
 */
export function roundAdoptions(
  state: RoundsState,
  utterances: readonly Utterance[],
  era2: ReadonlySet<number>,
  roundId: string,
  endedAt: Date,
): RoundAdoption[] {
  const round = state.rounds.find((r) => r.roundId === roundId);
  if (!round || round.kind !== 'sweep') return [];
  const asOf: RoundsState = {
    ...state,
    rounds: state.rounds.filter((r) => r.kind !== 'sweep' || r.startedAt <= round.startedAt),
  };
  const until = endedAt.getTime();
  const { spreads, starts } = collectSpreads(
    asOf,
    utterances.filter((u) => u.createdAt.getTime() <= until),
    era2,
  );
  const index = starts.indexOf(Date.parse(round.startedAt));
  const nameOf = new Map(state.roster.map((u) => [u.id, u.username]));
  const out: RoundAdoption[] = [];
  for (const s of spreads.values()) {
    const adopters = adoptersOf(s);
    if (adopters.length < MIN_ADOPTERS) continue;
    const here = adopters.filter((u) => s.firstRound.get(u) === index);
    if (here.length === 0) continue;
    out.push({
      token: s.token,
      origin: nameOf.get(s.origin) as string,
      adopters: here.map((u) => nameOf.get(u) as string).sort(),
    });
  }
  return out
    .sort(
      (a, b) =>
        b.adopters.length - a.adopters.length ||
        (a.token < b.token ? -1 : a.token > b.token ? 1 : 0),
    )
    .slice(0, ROUND_ADOPTIONS_LIMIT);
}
```

```ts
/**
 * The round digest (lab v2 §4): a pure function of rows the loader read, so it
 * is unit-tested without a database. What happened in one round — outcomes
 * per arm, the posts, highlights, conversations, interactions, dreams and the
 * words that spread — computed deterministically; nothing here is
 * model-written. Numbers are rounded to 4 decimals so `digestHash` is stable.
 */
import { createHash } from 'node:crypto';
import { finiteOr, finiteOrNull } from '../../../lib/numeric';
import { ARMS } from '../lab/roster';
import type { RoundDTO } from '../../../contract/lab/arms';
import type { RoundDigestDTO } from '../../../contract/lab/rounds';
import type { RoundAdoption } from '../arms/contagion';
import type { KindedEdge } from '../arms/homophily';
import { cosine } from '../arms/metrics';
import { cardKey, type RosterUser, type RoundCard } from '../arms/rounds';

export const EXCERPT_MAX = 140;
export const HIGHLIGHT_LIMIT = 3;
export const CONVERSATION_LIMIT = 5;

/** The digest as cached and hashed (the v2.1 observation is attached per request). */
export type Digest = Omit<RoundDigestDTO, 'observation'>;
export type DigestBody = Omit<Digest, 'digestHash'>;

/** An active public post with a vector filed under this round. */
export interface DigestPostRow {
  postId: string;
  userId: string;
  text: string;
  cardSim: number | null;
  maxSim: number | null;
  embedding: number[];
}
/** The first similarity row per account of this round. */
export interface DigestCandidateRow {
  userId: string;
  dropped: boolean;
}
/** An active comment by a roster account, in the window, on an active public post. */
export interface DigestCommentRow {
  postId: string;
  authorId: string;
  postAuthorId: string;
}
/** A dream snapshot captured in the window. */
export interface DigestDreamRow {
  userId: string;
  capturedAt: Date;
  driftFromAnchor: number;
  driftFromPrev: number;
}

export interface DigestInput {
  round: RoundDTO;
  /** The newest card of the round; the window is `[round.startedAt, endedAt]`. */
  endedAt: Date;
  roster: readonly RosterUser[];
  /** This round's deduplicated roster cards. */
  cards: readonly RoundCard[];
  /** `cardKey(userId, roundId)` of model-mismatch cycles. */
  mismatches: ReadonlySet<string>;
  candidates: readonly DigestCandidateRow[];
  posts: readonly DigestPostRow[];
  edges: readonly KindedEdge[];
  comments: readonly DigestCommentRow[];
  dreams: readonly DigestDreamRow[];
  /** `roundAdoptions(...)` for this round. */
  newWords: readonly RoundAdoption[];
}

type PostRef = DigestBody['highlights']['mostInCharacter'][number];
type DigestPost = DigestBody['posts'][number];

const cmp = (a: string, b: string): number => (a < b ? -1 : a > b ? 1 : 0);
const r4 = (x: number | null): number | null => (x === null ? null : Math.round(x * 1e4) / 1e4);

function excerptOf(text: string): string {
  const chars = Array.from(text.replace(/\s+/g, ' ').trim());
  if (chars.length <= EXCERPT_MAX) return chars.join('');
  return `${chars.slice(0, EXCERPT_MAX - 1).join('')}…`;
}

function zeroOutcomes(): DigestBody['outcomes'] {
  return Object.fromEntries(
    ARMS.map((a) => [
      a.id,
      {
        cards: 0,
        landed: 0,
        attempted: 0,
        failures: 0,
        missing: 0,
        dreams: 0,
        guardDrops: 0,
        missingPostVectors: 0,
        deviations: 0,
      },
    ]),
  ) as DigestBody['outcomes'];
}

export function buildDigest(input: DigestInput): Digest {
  const body = digestBody(input);
  return { ...body, digestHash: digestHashOf(body) };
}

function digestBody(input: DigestInput): DigestBody {
  const { round } = input;
  const byId = new Map(input.roster.map((u) => [u.id, u]));
  const userOf = (id: string) => byId.get(id) as RosterUser;
  const isDeviation = (userId: string) => input.mismatches.has(cardKey(userId, round.roundId));

  // ── outcomes ──
  const outcomes = zeroOutcomes();
  for (const c of input.cards) {
    const u = byId.get(c.userId);
    if (!u) continue;
    const o = outcomes[u.arm];
    o.cards += 1;
    o.landed += finiteOr(c.metrics.landed, 0);
    o.attempted += finiteOr(c.metrics.attempted, 0);
    if (c.outcome === 'fail') o.failures += 1;
    if (c.metrics.dreamAccepted === true) o.dreams += 1;
    if (c.metrics.missingPostVector === true) o.missingPostVectors += 1;
    if (isDeviation(c.userId)) o.deviations += 1;
  }
  for (const a of ARMS) {
    const o = outcomes[a.id];
    o.missing = round.kind === 'sweep' ? Math.max(0, a.usernames.length - o.cards) : 0;
  }
  for (const cand of input.candidates) {
    const u = byId.get(cand.userId);
    if (u && cand.dropped) outcomes[u.arm].guardDrops += 1;
  }

  // ── posts ──
  const rosterPosts = input.posts.filter((p) => byId.has(p.userId));
  const convOf = (p: DigestPostRow): number | null => {
    const sims: number[] = [];
    for (const q of rosterPosts) {
      if (q.userId === p.userId) continue;
      const s = cosine(p.embedding, q.embedding);
      if (s !== null) sims.push(s);
    }
    return sims.length ? sims.reduce((a, b) => a + b, 0) / sims.length : null;
  };
  const armIndex = new Map(ARMS.map((a, i) => [a.id, i]));
  const posts: DigestPost[] = rosterPosts
    .map((p) => {
      const u = userOf(p.userId);
      return {
        postId: p.postId,
        username: u.username,
        arm: u.arm,
        excerpt: excerptOf(p.text),
        cardSim: r4(finiteOrNull(p.cardSim)),
        maxSim: r4(finiteOrNull(p.maxSim)),
        conv: r4(convOf(p)),
        deviation: isDeviation(p.userId),
      };
    })
    .sort(
      (a, b) =>
        (armIndex.get(a.arm) as number) - (armIndex.get(b.arm) as number) ||
        cmp(a.username, b.username) ||
        cmp(a.postId, b.postId),
    );

  // ── highlights ──
  const ref = (p: { postId: string; username: string }): PostRef => ({
    postId: p.postId,
    username: p.username,
  });
  const scored = posts
    .filter((p) => !p.deviation && p.cardSim !== null)
    .sort((a, b) => (b.cardSim as number) - (a.cardSim as number) || cmp(a.postId, b.postId));
  const topN = Math.min(HIGHLIGHT_LIMIT, Math.ceil(scored.length / 2));
  const rest = scored.slice(topN);
  const mostInCharacter = scored.slice(0, topN).map(ref);
  const leastInCharacter =
    rest.length === 0
      ? []
      : rest
          .slice(-Math.min(HIGHLIGHT_LIMIT, rest.length))
          .reverse()
          .map(ref);

  const clean = rosterPosts.filter((p) => !isDeviation(p.userId));
  const pairs: Array<{ a: DigestPostRow; b: DigestPostRow; sim: number }> = [];
  for (let i = 0; i < clean.length; i++) {
    for (let j = i + 1; j < clean.length; j++) {
      if (clean[i].userId === clean[j].userId) continue;
      const sim = cosine(clean[i].embedding, clean[j].embedding);
      if (sim === null) continue;
      const [a, b] =
        clean[i].postId < clean[j].postId ? [clean[i], clean[j]] : [clean[j], clean[i]];
      pairs.push({ a, b, sim: r4(sim) as number });
    }
  }
  const mostAlike = pairs
    .sort((x, y) => y.sim - x.sim || cmp(x.a.postId, y.a.postId) || cmp(x.b.postId, y.b.postId))
    .slice(0, HIGHLIGHT_LIMIT)
    .map(({ a, b, sim }) => ({
      a: { postId: a.postId, username: userOf(a.userId).username },
      b: { postId: b.postId, username: userOf(b.userId).username },
      sim,
    }));

  const threads = new Map<string, { authorId: string; commenters: Set<string>; comments: number }>();
  for (const c of input.comments) {
    if (!byId.has(c.authorId)) continue;
    const t = threads.get(c.postId) ?? {
      authorId: c.postAuthorId,
      commenters: new Set<string>(),
      comments: 0,
    };
    t.commenters.add(c.authorId);
    t.comments += 1;
    threads.set(c.postId, t);
  }
  const conversations = [...threads]
    .filter(([, t]) => t.commenters.size >= 2)
    .map(([postId, t]) => {
      const ids = new Set(t.commenters);
      if (byId.has(t.authorId)) ids.add(t.authorId);
      const people = [...ids].map(userOf);
      return {
        postId,
        participants: people.map((p) => p.username).sort(cmp),
        crossArm: new Set(people.map((p) => p.arm)).size > 1,
        comments: t.comments,
      };
    })
    .sort((a, b) => b.comments - a.comments || cmp(a.postId, b.postId))
    .slice(0, CONVERSATION_LIMIT);

  // ── interactions ──
  const agg = new Map<string, DigestBody['interactions']['edges'][number]>();
  let total = 0;
  let cross = 0;
  for (const e of input.edges) {
    const s = byId.get(e.source);
    const t = byId.get(e.target);
    if (!s || !t || s.id === t.id || e.n <= 0) continue;
    const key = `${s.username}|${t.username}|${e.kind}`;
    const row = agg.get(key) ?? { from: s.username, to: t.username, kind: e.kind, count: 0 };
    row.count += e.n;
    agg.set(key, row);
    total += e.n;
    if (s.arm !== t.arm) cross += e.n;
  }
  const edges = [...agg.values()].sort(
    (a, b) =>
      b.count - a.count || cmp(a.from, b.from) || cmp(a.to, b.to) || cmp(a.kind, b.kind),
  );

  // ── changes ──
  const dreams = input.dreams
    .filter((d) => byId.has(d.userId))
    .map((d) => {
      const u = userOf(d.userId);
      return {
        username: u.username,
        arm: u.arm,
        capturedAt: d.capturedAt.toISOString(),
        driftFromAnchor: r4(finiteOr(d.driftFromAnchor, 0)) as number,
        driftFromPrev: r4(finiteOr(d.driftFromPrev, 0)) as number,
      };
    })
    .sort((a, b) => cmp(a.username, b.username) || cmp(a.capturedAt, b.capturedAt));
  const newWords = input.newWords.map((w) => ({
    token: w.token,
    origin: w.origin,
    adopters: [...w.adopters],
  }));

  return {
    round: {
      roundId: round.roundId,
      kind: round.kind,
      startedAt: round.startedAt,
      endedAt: input.endedAt.toISOString(),
      ordinal: round.ordinal,
      completed: round.completed,
    },
    outcomes,
    posts,
    highlights: { mostInCharacter, leastInCharacter, mostAlike, conversations },
    interactions: { total, crossArm: cross, withinArm: total - cross, edges },
    changes: { dreams, newWords },
  };
}

/** JSON with object keys sorted at every depth; `undefined` members dropped. */
export function canonicalJson(value: unknown): string {
  if (value === null || typeof value !== 'object') return JSON.stringify(value);
  if (Array.isArray(value)) return `[${value.map(canonicalJson).join(',')}]`;
  const entries = Object.entries(value as Record<string, unknown>)
    .filter(([, v]) => v !== undefined)
    .sort(([a], [b]) => cmp(a, b));
  return `{${entries.map(([k, v]) => `${JSON.stringify(k)}:${canonicalJson(v)}`).join(',')}}`;
}

/** sha256 of the canonical body; observer notes cite it, so a changed round reads as stale. */
export function digestHashOf(body: DigestBody): string {
  return createHash('sha256').update(canonicalJson(body)).digest('hex');
}
```

```ts
/**
 * Round reads (lab v2 §4): the round list and one round's digest. Rounds come
 * from `arms/rounds.ts` — the same definition the arms report uses; nothing
 * here re-derives one. Read-only: nothing a persona reads is touched.
 *
 * Caches: the rounds state and the list 60 s; the newest round's digest 60 s,
 * older rounds' 1 h (their rows no longer change). No precomputed table.
 */
import { and, asc, between, count, eq, inArray, sql } from 'drizzle-orm';
import { db } from '../../../db/client';
import { agentEvents, comments, personalitySnapshots, posts, postVectors } from '../../../db/schema';
import { AppError } from '../../../lib/errors';
import { TTLCache } from '../../../lib/ttlCache';
import type { RoundDTO } from '../../../contract/lab/arms';
import type { RoundsListDTO } from '../../../contract/lab/rounds';
import { loadContagionInputs, roundAdoptions } from '../arms/contagion';
import { loadInteractionEdges, type TimeWindow } from '../arms/homophily';
import { SIMILARITY_SUMMARIES } from '../arms/metrics';
import { loadRoundsState, parseRoundId, type RoundsState } from '../arms/rounds';
import {
  buildDigest,
  type Digest,
  type DigestCandidateRow,
  type DigestCommentRow,
  type DigestDreamRow,
  type DigestPostRow,
} from './digest';

export const ROUNDS_LIST_LIMIT = 60;
const NEWEST_TTL_MS = 60_000;
const OLDER_TTL_MS = 60 * 60_000;

const stateCache = new TTLCache<'state', RoundsState>(NEWEST_TTL_MS);
const listCache = new TTLCache<'list', RoundsListDTO>(NEWEST_TTL_MS);
const newestDigests = new TTLCache<string, Digest>(NEWEST_TTL_MS);
const olderDigests = new TTLCache<string, Digest>(OLDER_TTL_MS);

/** Test hook: every round cache. */
export function clearRoundCaches(): void {
  stateCache.clear();
  listCache.clear();
  newestDigests.clear();
  olderDigests.clear();
}

/** The list only (a new observation flips `hasObservation`, v2.1). */
export function clearRoundsListCache(): void {
  listCache.clear();
}

function roundsState(): Promise<RoundsState> {
  return stateCache.getOrLoad('state', loadRoundsState);
}

const publicPost = and(eq(posts.status, 'active'), eq(posts.visibility, 'public'));

/** 400 on an id that is not a real UTC instant in the round format; 404 when no roster card carries it. */
export async function findRound(roundId: string): Promise<{ state: RoundsState; round: RoundDTO }> {
  if (!parseRoundId(roundId)) throw AppError.validation('Invalid round id', { roundId: 'FORMAT' });
  const state = await roundsState();
  const round = state.rounds.find((r) => r.roundId === roundId);
  if (!round) throw AppError.notFound('Round not found');
  return { state, round };
}

export async function getRoundsList(): Promise<RoundsListDTO> {
  return listCache.getOrLoad('list', computeRoundsList);
}

async function computeRoundsList(): Promise<RoundsListDTO> {
  const state = await roundsState();
  const newest = state.rounds.slice().reverse().slice(0, ROUNDS_LIST_LIMIT);
  if (newest.length === 0) return { rounds: [] };
  const ids = newest.map((r) => r.roundId);
  const postRows = await db
    .select({ roundId: postVectors.roundId, n: count() })
    .from(postVectors)
    .innerJoin(posts, eq(posts.id, postVectors.postId))
    .where(
      and(
        inArray(postVectors.roundId, ids),
        inArray(
          postVectors.userId,
          state.roster.map((u) => u.id),
        ),
        publicPost,
      ),
    )
    .groupBy(postVectors.roundId);
  const postsBy = new Map(postRows.map((r) => [r.roundId as string, r.n]));
  const failuresBy = new Map<string, number>();
  for (const c of state.cards) {
    if (c.outcome === 'fail') failuresBy.set(c.roundId, (failuresBy.get(c.roundId) ?? 0) + 1);
  }
  return {
    rounds: newest.map((r) => ({
      roundId: r.roundId,
      kind: r.kind,
      startedAt: r.startedAt,
      ordinal: r.ordinal,
      completed: r.completed,
      cards: r.cards,
      posts: postsBy.get(r.roundId) ?? 0,
      failures: failuresBy.get(r.roundId) ?? 0,
    })),
  };
}

export async function getRoundDigest(roundId: string): Promise<Digest> {
  const { state, round } = await findRound(roundId);
  const newest = state.rounds[state.rounds.length - 1].roundId === roundId;
  return (newest ? newestDigests : olderDigests).getOrLoad(roundId, () =>
    computeDigest(state, round),
  );
}

async function computeDigest(state: RoundsState, round: RoundDTO): Promise<Digest> {
  const cards = state.cards.filter((c) => c.roundId === round.roundId);
  const endedAt = new Date(Math.max(...cards.map((c) => c.createdAt.getTime())));
  const window: TimeWindow = { from: new Date(round.startedAt), to: endedAt };
  const userIds = state.roster.map((u) => u.id);
  const [candidates, postRows, edges, commentRows, dreams, contagion] = await Promise.all([
    loadCandidates(userIds, round.roundId),
    loadPosts(userIds, round.roundId),
    loadInteractionEdges(state.roster, window),
    loadComments(userIds, window),
    loadDreams(userIds, window),
    loadContagionInputs(state),
  ]);
  return buildDigest({
    round,
    endedAt,
    roster: state.roster,
    cards,
    mismatches: state.mismatches,
    candidates,
    posts: postRows,
    edges,
    comments: commentRows,
    dreams,
    newWords: roundAdoptions(state, contagion.utterances, contagion.era2, round.roundId, endedAt),
  });
}

/** The first similarity row per account of this round (as the reliability block counts them). */
async function loadCandidates(userIds: string[], roundId: string): Promise<DigestCandidateRow[]> {
  const rows = await db
    .select({ userId: agentEvents.userId, metrics: agentEvents.metrics })
    .from(agentEvents)
    .where(
      and(
        inArray(agentEvents.userId, userIds),
        eq(agentEvents.type, 'cycle'),
        eq(agentEvents.phase, 'act'),
        inArray(agentEvents.summary, [...SIMILARITY_SUMMARIES]),
        sql`${agentEvents.metrics}->>'roundId' = ${roundId}`,
      ),
    )
    .orderBy(asc(agentEvents.createdAt), asc(agentEvents.id));
  const seen = new Set<string>();
  const out: DigestCandidateRow[] = [];
  for (const r of rows) {
    if (seen.has(r.userId)) continue;
    seen.add(r.userId);
    out.push({ userId: r.userId, dropped: r.metrics.dropped === true });
  }
  return out;
}

/** This round's post vectors whose post is active and public; embeddings stay server-side. */
async function loadPosts(userIds: string[], roundId: string): Promise<DigestPostRow[]> {
  return db
    .select({
      postId: postVectors.postId,
      userId: postVectors.userId,
      text: posts.text,
      cardSim: postVectors.cardSim,
      maxSim: postVectors.maxSim,
      embedding: postVectors.embedding,
    })
    .from(postVectors)
    .innerJoin(posts, eq(posts.id, postVectors.postId))
    .where(and(eq(postVectors.roundId, roundId), inArray(postVectors.userId, userIds), publicPost))
    .orderBy(asc(postVectors.createdAt), asc(postVectors.id));
}

async function loadComments(userIds: string[], window: TimeWindow): Promise<DigestCommentRow[]> {
  return db
    .select({ postId: comments.postId, authorId: comments.authorId, postAuthorId: posts.authorId })
    .from(comments)
    .innerJoin(posts, eq(comments.postId, posts.id))
    .where(
      and(
        inArray(comments.authorId, userIds),
        eq(comments.status, 'active'),
        publicPost,
        between(comments.createdAt, window.from, window.to),
      ),
    );
}

async function loadDreams(userIds: string[], window: TimeWindow): Promise<DigestDreamRow[]> {
  return db
    .select({
      userId: personalitySnapshots.userId,
      capturedAt: personalitySnapshots.capturedAt,
      driftFromAnchor: personalitySnapshots.driftFromAnchor,
      driftFromPrev: personalitySnapshots.driftFromPrev,
    })
    .from(personalitySnapshots)
    .where(
      and(
        inArray(personalitySnapshots.userId, userIds),
        eq(personalitySnapshots.snapshotType, 'dream'),
        between(personalitySnapshots.capturedAt, window.from, window.to),
      ),
    );
}
```

A round in `state.rounds` always has ≥ 1 card, so `userIds` is never empty here and `Math.max` has an argument.

```tsx
/**
 * `RoundDigest` — one round in plain terms (lab v2 §6): outcomes per arm,
 * highlights, conversations, interactions, who dreamed and which new words
 * spread. Every number comes from `GET /agents/rounds/:roundId`, computed from
 * stored rows; nothing here is model-written.
 */
import type { ReactNode } from 'react';
import { useTranslation } from 'react-i18next';
import { Link } from 'react-router-dom';
import { Card } from '@/components/primitives';
import type { RoundDigestDTO } from '@/features/lab/types';
import { ArmName } from '@/features/lab/metrics/ArmName';
import { ARM_IDS } from '@/features/lab/metrics/armColors';
import { fmtNum } from '@/features/lab/metrics/format';
import s from './v2.module.css';

type PostRef = RoundDigestDTO['highlights']['mostInCharacter'][number];

export function RoundDigest({ digest }: { digest: RoundDigestDTO }) {
  const { t } = useTranslation();
  const postById = new Map(digest.posts.map((p) => [p.postId, p]));
  const { highlights, interactions, changes } = digest;

  const postLink = (ref: PostRef) => {
    const p = postById.get(ref.postId);
    return (
      <span className={s.postRef}>
        <Link to={`/u/${ref.username}`}>@{ref.username}</Link>{' '}
        <Link to={`/p/${ref.postId}`}>{p?.excerpt || ref.postId}</Link>
        {p && p.cardSim !== null && <span className={s.num}> {fmtNum(p.cardSim)}</span>}
      </span>
    );
  };

  const block = (title: string, testId: string, items: ReactNode[]) => (
    <div className={s.block} data-testid={testId}>
      <h3 className={s.blockTitle}>{title}</h3>
      {items.length === 0 ? (
        <p className={s.note}>{t('lab.v2.digest.none')}</p>
      ) : (
        <ol className={s.list}>{items}</ol>
      )}
    </div>
  );

  return (
    <Card as="section" className={s.digest}>
      <h2 className={s.sectionTitle}>
        {t('lab.v2.digest.title', { roundId: digest.round.roundId })}
      </h2>

      <div className={s.outcomes}>
        {ARM_IDS.map((arm) => {
          const o = digest.outcomes[arm];
          return (
            <div key={arm} className={s.outcome} data-testid={`outcome-${arm}`}>
              <span>
                <ArmName arm={arm} />
              </span>
              <span>{t('lab.v2.digest.cards', { n: o.cards })}</span>
              <span>
                {t('lab.v2.digest.landed', { landed: o.landed, attempted: o.attempted })}
              </span>
              {o.failures > 0 && (
                <span className={s.warn}>{t('lab.v2.digest.failures', { n: o.failures })}</span>
              )}
              {o.missing > 0 && (
                <span className={s.warn}>{t('lab.v2.digest.missing', { n: o.missing })}</span>
              )}
              {o.dreams > 0 && <span>{t('lab.v2.digest.dreams', { n: o.dreams })}</span>}
              {o.guardDrops > 0 && (
                <span>{t('lab.v2.digest.guardDrops', { n: o.guardDrops })}</span>
              )}
              {o.missingPostVectors > 0 && (
                <span>{t('lab.v2.digest.missingVectors', { n: o.missingPostVectors })}</span>
              )}
              {o.deviations > 0 && (
                <span className={s.warn}>
                  {t('lab.v2.digest.deviations', { n: o.deviations })}
                </span>
              )}
            </div>
          );
        })}
      </div>

      <div className={s.grid}>
        {block(
          t('lab.v2.digest.mostIn'),
          'most-in',
          highlights.mostInCharacter.map((r) => <li key={r.postId}>{postLink(r)}</li>),
        )}
        {block(
          t('lab.v2.digest.leastIn'),
          'least-in',
          highlights.leastInCharacter.map((r) => <li key={r.postId}>{postLink(r)}</li>),
        )}
        {block(
          t('lab.v2.digest.mostAlike'),
          'most-alike',
          highlights.mostAlike.map((m) => (
            <li key={`${m.a.postId}-${m.b.postId}`}>
              {postLink(m.a)} ↔ {postLink(m.b)} <span className={s.num}>{fmtNum(m.sim)}</span>
            </li>
          )),
        )}
        {block(
          t('lab.v2.digest.conversations'),
          'conversations',
          highlights.conversations.map((c) => (
            <li key={c.postId}>
              <Link to={`/p/${c.postId}`}>{c.participants.map((u) => `@${u}`).join(' · ')}</Link>{' '}
              <span className={s.num}>{t('lab.v2.digest.comments', { n: c.comments })}</span>
              {c.crossArm && <span className={s.badge}>{t('lab.v2.digest.crossArm')}</span>}
            </li>
          )),
        )}
      </div>

      <p className={s.note}>
        {t('lab.v2.digest.interactions', {
          total: interactions.total,
          cross: interactions.crossArm,
          within: interactions.withinArm,
        })}
      </p>

      <div className={s.grid}>
        {block(
          t('lab.v2.digest.dreamsTitle'),
          'dreams',
          changes.dreams.map((d) => (
            <li key={`${d.username}-${d.capturedAt}`}>
              <Link to={`/u/${d.username}`}>@{d.username}</Link> <ArmName arm={d.arm} />{' '}
              <span className={s.num}>
                {t('lab.v2.digest.drift', { v: fmtNum(d.driftFromPrev) })}
              </span>
            </li>
          )),
        )}
        {block(
          t('lab.v2.digest.newWords'),
          'new-words',
          changes.newWords.map((w) => (
            <li key={w.token}>
              <strong>{w.token}</strong>{' '}
              <span className={s.note}>
                {t('lab.v2.digest.adoptedBy', {
                  origin: w.origin,
                  adopters: w.adopters.map((u) => `@${u}`).join(', '),
                })}
              </span>
            </li>
          )),
        )}
      </div>
    </Card>
  );
}
```

```tsx
const fmtUtc = (ms: number): string => `${new Date(ms).toISOString().slice(0, 16).replace('T', ' ')} UTC`;

  now,

      </span>

        <span>
          {eta > now ? t('lab.v2.strip.next', { eta: fmtUtc(eta) }) : t('lab.v2.strip.nextDue')}
        </span>
      )}
      <span>{t('lab.v2.strip.provisional', { target: report.targetRounds })}</span>
```

```tsx
/**
 * Lab v2 (docs/superpowers/specs/2026-10-17-lab-v2-design.md): narrative first —
 * the experiment strip, one round's digest (`?round=`, default the newest
 * sweep), storylines (`?agent=`), then the experiment metrics. The older lab
 * (Era 2, graph, Bench) lives unchanged at `/lab/v1`.
 */
import type { ReactNode } from 'react';
import { useQuery } from '@tanstack/react-query';
import { useTranslation } from 'react-i18next';
import { Link, useSearchParams } from 'react-router-dom';
import { Skeleton } from '@/components/primitives';
import { getArmsReport, getRoundDigest, listLabAgents, listRounds } from '@/features/lab/api';
import { labKeys, LAB_STALE_MS } from '@/features/lab/queries';
import type { RoundListItem } from '@/features/lab/types';
import labStyles from '@/features/lab/lab.module.css';
import { ArmsMetrics } from '@/features/lab/metrics/ArmsMetrics';
import { usePageTitle } from '@/lib/usePageTitle';
import { ExperimentStrip } from './ExperimentStrip';
import { RoundDigest } from './RoundDigest';
import { RoundPicker } from './RoundPicker';
import { Storylines } from './Storylines';
import s from './v2.module.css';

/** Newest sweep round, else the newest round of any kind (the list is newest first). */
export function defaultRoundId(rounds: RoundListItem[]): string | null {
  return rounds.find((r) => r.kind === 'sweep')?.roundId ?? rounds[0]?.roundId ?? null;
}

/** A malformed (400) or unknown (404) round id. */
export function isMissingRound(err: unknown): boolean {
  const status = (err as { status?: number } | null)?.status;
  return status === 404 || status === 400;
}

export default function LabV2Page() {
  const { t } = useTranslation();
  usePageTitle('Lab');
  const [params, setParams] = useSearchParams();
  const roundParam = params.get('round');
  const focused = params.get('agent');

  const roundsQ = useQuery({ queryKey: labKeys.rounds, queryFn: listRounds, staleTime: LAB_STALE_MS });
  const armsQ = useQuery({ queryKey: labKeys.arms, queryFn: getArmsReport, staleTime: LAB_STALE_MS });
  const agentsQ = useQuery({
    queryKey: labKeys.agents(3),
    queryFn: () => listLabAgents(3, 100),
    staleTime: LAB_STALE_MS,
  });
  const rounds = roundsQ.data?.rounds ?? [];
  const selected = roundParam ?? defaultRoundId(rounds);
  const digestQ = useQuery({
    queryKey: labKeys.round(selected ?? ''),
    queryFn: () => getRoundDigest(selected as string),
    enabled: selected !== null,
    staleTime: LAB_STALE_MS,
    // A missing round is an answer, not a blip; the error states offer their own way on.
    retry: false,
  });

  const setParam = (key: 'round' | 'agent', value: string | null) => {
    const next = new URLSearchParams(params);
    if (value) next.set(key, value);
    else next.delete(key);
    setParams(next, { replace: true });
  };

  const status = (label: string) => (
    <div aria-label={label} role="status">
      <Skeleton height={160} width="100%" />
    </div>
  );

  let digestBody: ReactNode;
  if (roundParam === null && roundsQ.isLoading) {
    digestBody = status(t('lab.v2.digest.loading'));
  } else if (roundParam === null && roundsQ.isError) {
    digestBody = (
      <div className={labStyles.emptyState}>
        {t('lab.v2.digest.error')}{' '}
        <button type="button" onClick={() => void roundsQ.refetch()}>
          {t('lab.v2.digest.retry')}
        </button>
      </div>
    );
  } else if (selected === null) {
    digestBody = <div className={labStyles.emptyState}>{t('lab.v2.digest.empty')}</div>;
  } else if (digestQ.isError && isMissingRound(digestQ.error)) {
    digestBody = (
      <div className={labStyles.emptyState}>
        {t('lab.v2.digest.notFound')}{' '}
        <button type="button" onClick={() => setParam('round', null)}>
          {t('lab.v2.digest.backToNewest')}
        </button>
      </div>
    );
  } else if (digestQ.isError) {
    digestBody = (
      <div className={labStyles.emptyState}>
        {t('lab.v2.digest.error')}{' '}
        <button type="button" onClick={() => void digestQ.refetch()}>
          {t('lab.v2.digest.retry')}
        </button>
      </div>
    );
  } else if (!digestQ.data) {
    digestBody = status(t('lab.v2.digest.loading'));
  } else {
    digestBody = <RoundDigest digest={digestQ.data} />;
  }

  return (
    <div className={`${labStyles.page} ${s.page}`}>
      <header className={labStyles.header}>
        <div>
          <h1>{t('lab.title')}</h1>
          <div className={labStyles.headerSub}>{t('lab.v2.sub')}</div>
        </div>
        <nav className={labStyles.headerActions}>
          <Link to="/lab/v1?view=benchmark">{t('lab.v2.bench')}</Link>
          <Link to="/lab/v1">{t('lab.v2.olderView')}</Link>
        </nav>
      </header>

      {armsQ.data && <ExperimentStrip report={armsQ.data} rounds={rounds} now={Date.now()} />}

      {selected !== null && rounds.length > 0 && (
        <RoundPicker rounds={rounds} value={selected} onChange={(id) => setParam('round', id)} />
      )}
      {digestBody}

      <Storylines
        agents={agentsQ.data ?? []}
        loading={agentsQ.isLoading}
        focused={focused}
        onFocus={(u) => setParam('agent', u)}
        onClose={() => setParam('agent', null)}
      />

      <section className={s.digest}>
        <h2 className={s.sectionTitle}>{t('lab.v2.metrics.title')}</h2>
        {armsQ.data ? (
          <ArmsMetrics report={armsQ.data} />
        ) : armsQ.isError ? (
          <div className={labStyles.emptyState}>{t('lab.era3.error')}</div>
        ) : (
          status(t('lab.era3.loading'))
        )}
      </section>
    </div>
  );
}
```

```ts
/**
 * Lab v1 deep links (`?era=2`, `?view=graph`, `?view=benchmark`) now live at
 * `/lab/v1`. The target keeps the query string exactly, so no shared URL breaks.
 * Anything else (including `?agent=`) stays on v2.
 */
export function v1DeepLink(search: string): string | null {
  const params = new URLSearchParams(search);
  const view = params.get('view');
  const v1 = params.get('era') === '2' || view === 'graph' || view === 'benchmark';
  if (!v1) return null;
  const query = search.startsWith('?') ? search : `?${search}`;
  return `/lab/v1${query}`;
}
```

```ts
import { createHash, timingSafeEqual } from 'node:crypto';
import type { NextFunction, Request, Response } from 'express';
import { env } from '../../../config/env';
import { AppError } from '../../../lib/errors';

export const OBSERVER_TOKEN_HEADER = 'x-lab-observer-token';

const sha256 = (s: string): Buffer => createHash('sha256').update(s, 'utf8').digest();

/**
 * The one lab write no session may make: the observer note (lab v2 §5). With
 * `LAB_OBSERVER_TOKEN` unset the route answers 404 — the feature is off.
 * Otherwise the header must match, compared in constant time over sha256
 * digests (equal length whatever was sent), else 401. A session cookie or an
 * API key is neither needed nor sufficient.
 */
export function requireObserverToken(req: Request, _res: Response, next: NextFunction): void {
  const expected = env.LAB_OBSERVER_TOKEN;
  if (!expected) return next(AppError.notFound('Not found'));
  const sent = req.get(OBSERVER_TOKEN_HEADER);
  if (!sent || !timingSafeEqual(sha256(sent), sha256(expected))) {
    return next(AppError.unauthenticated('Invalid observer token'));
  }
  next();
}
```

```ts
/**
 * The observer note (lab v2 §5): one row per round, written only by the
 * operator's `swil-agent observe` (token-gated route), read with the digest.
 * The note is presentation, never data — nothing a persona reads touches it.
 */
import { eq } from 'drizzle-orm';
import { db } from '../../../db/client';
import { roundObservations } from '../../../db/schema';
import type {
  RoundDigestDTO,
  RoundObservationPut,
  RoundObservationPutResult,
} from '../../../contract/lab/rounds';
import { clearRoundsListCache, findRound, getRoundDigest } from './roundReads';

/** The cached digest plus this round's note, read per request so a new note shows at once. */
export async function getRoundView(roundId: string): Promise<RoundDigestDTO> {
  const digest = await getRoundDigest(roundId);
  const [row] = await db
    .select()
    .from(roundObservations)
    .where(eq(roundObservations.roundId, roundId))
    .limit(1);
  return {
    ...digest,
    observation: row
      ? {
          text: row.text,
          model: row.model,
          digestHash: row.digestHash,
          stale: row.digestHash !== digest.digestHash,
          updatedAt: row.updatedAt.toISOString(),
        }
      : null,
  };
}

/** Insert or replace the round's note. 400/404 like the digest read for a bad or unknown round. */
export async function putObservation(
  roundId: string,
  input: RoundObservationPut,
): Promise<RoundObservationPutResult> {
  await findRound(roundId);
  const now = new Date();
  const [row] = await db
    .insert(roundObservations)
    .values({ roundId, ...input, createdAt: now, updatedAt: now })
    .onConflictDoUpdate({
      target: roundObservations.roundId,
      set: {
        text: input.text,
        model: input.model,
        digestHash: input.digestHash,
        promptVersion: input.promptVersion,
        updatedAt: now,
      },
    })
    .returning({ roundId: roundObservations.roundId, updatedAt: roundObservations.updatedAt });
  clearRoundsListCache();
  return { roundId: row.roundId, updatedAt: row.updatedAt.toISOString() };
}
```

- [ ] **Step 5: `analysis/observe.py`**

```python
"""`swil-agent observe <roundId>`: one machine-written note per round (lab v2 §5).

GET the round's digest (a public lab read), make ONE completion through the
isolated, tool-less claude backend on the observer's fixed model, and PUT the
note with the operator's observer token. Not a persona: no persona file, no
feed -- nothing a persona reads changes. The note is presentation, never data;
the round script runs this with `|| true`, so a failed note never fails a round.

The digest is sent WITHOUT any stored `observation`: a note never reads the
previous note. Re-running replaces the note on the server.
"""

from __future__ import annotations

import json
import logging
from dataclasses import dataclass
from typing import Any, Final

import httpx

from swil_agent.api.dto import cap_utf16
from swil_agent.config import Settings
from swil_agent.llm.complete import complete_text
from swil_agent.llm.errors import BackendUnavailableError
from swil_agent.llm.protocol import Backend
from swil_agent.llm.runner import CompletionRequest
from swil_agent.prompts.observer import OBSERVER_MODEL, OBSERVER_PROMPT_VERSION, OBSERVER_SYSTEM
from swil_agent.round_id import is_valid_round_id

logger = logging.getLogger(__name__)

OBSERVER_TOKEN_HEADER: Final = "X-Lab-Observer-Token"
# The server's `text.max(1200)`, which counts UTF-16 units.
OBSERVATION_MAX_UNITS: Final = 1200
_HTTP_TIMEOUT: Final = 30.0
_HEX: Final = frozenset("0123456789abcdef")


class ObserveError(RuntimeError):
    """A note that was not written. `kind`: `usage` (bad round id), `missing`
    (no such round), `setup` (token, server, model, or a refused write)."""

    def __init__(self, kind: str, message: str) -> None:
        super().__init__(message)
        self.kind = kind


@dataclass(frozen=True)
class Observation:
    round_id: str
    text: str
    digest_hash: str
    written: bool


def http_transport() -> httpx.BaseTransport | None:
    """The command's transport seam: `None` in production; a test returns a mock."""
    return None


def build_observer_request(digest: dict[str, Any]) -> CompletionRequest:
    body = {k: v for k, v in digest.items() if k != "observation"}
    return CompletionRequest(
        system=OBSERVER_SYSTEM,
        user=json.dumps(body, ensure_ascii=False, sort_keys=True),
        model=OBSERVER_MODEL,
    )


def observation_body(text: str, digest_hash: str) -> dict[str, str]:
    return {
        "text": text,
        "model": OBSERVER_MODEL,
        "digestHash": digest_hash,
        "promptVersion": OBSERVER_PROMPT_VERSION,
    }


def _is_hash(value: object) -> bool:
    return isinstance(value, str) and len(value) == 64 and set(value) <= _HEX


def _fetch_digest(client: httpx.Client, settings: Settings, round_id: str) -> dict[str, Any]:
    try:
        response = client.get(f"{settings.swil_url}/api/v1/agents/rounds/{round_id}")
    except httpx.HTTPError as exc:
        raise ObserveError("setup", f"digest read failed: {exc}") from exc
    if response.status_code == 404:
        raise ObserveError("missing", f"no round {round_id} on {settings.swil_url}")
    if response.status_code == 400:
        raise ObserveError("usage", f"the server refused round id {round_id!r}")
    if response.status_code >= 400:
        raise ObserveError("setup", f"digest read failed: HTTP {response.status_code}")
    try:
        parsed: Any = response.json()
    except ValueError as exc:
        raise ObserveError("setup", "the digest is not JSON") from exc
    data = parsed.get("data") if isinstance(parsed, dict) else None
    if not isinstance(data, dict) or not _is_hash(data.get("digestHash")):
        raise ObserveError("setup", "the digest carries no digestHash")
    return data


def _write(
    client: httpx.Client, settings: Settings, round_id: str, body: dict[str, str], token: str
) -> None:
    try:
        response = client.put(
            f"{settings.swil_url}/api/v1/agents/rounds/{round_id}/observation",
            json=body,
            headers={OBSERVER_TOKEN_HEADER: token},
        )
    except httpx.HTTPError as exc:
        raise ObserveError("setup", f"observation write failed: {exc}") from exc
    if response.status_code == 404:
        raise ObserveError(
            "setup", "observation write answered 404: LAB_OBSERVER_TOKEN is unset on the server"
        )
    if response.status_code == 401:
        raise ObserveError("setup", "observation write refused: the observer token does not match")
    if response.status_code >= 400:
        raise ObserveError(
            "setup", f"observation write failed: HTTP {response.status_code} {response.text[:200]}"
        )


def run_observe(
    settings: Settings,
    round_id: str,
    backend: Backend,
    *,
    dry_run: bool = False,
    transport: httpx.BaseTransport | None = None,
) -> Observation:
    if not is_valid_round_id(round_id):
        raise ObserveError("usage", f"{round_id!r} is not a round id (YYYYMMDDTHHMMSSZ-r|m)")
    token = settings.lab_observer_token
    secret = token.get_secret_value() if token is not None else None
    if secret is None and not dry_run:
        raise ObserveError("setup", "LAB_OBSERVER_TOKEN is unset in agent/.env")

    with httpx.Client(transport=transport, timeout=_HTTP_TIMEOUT) as client:
        digest = _fetch_digest(client, settings, round_id)
        try:
            raw = complete_text(backend, build_observer_request(digest))
        except BackendUnavailableError as exc:
            raise ObserveError("setup", f"observer model unavailable: {exc}") from exc
        text = cap_utf16(raw.strip(), OBSERVATION_MAX_UNITS).strip()
        if not text:
            raise ObserveError("setup", "the observer model returned nothing")
        digest_hash = str(digest["digestHash"])
        if dry_run or secret is None:
            return Observation(round_id, text, digest_hash, written=False)
        _write(client, settings, round_id, observation_body(text, digest_hash), secret)
    logger.info("observer note written for %s (digest %s)", round_id, digest_hash[:12])
    return Observation(round_id, text, digest_hash, written=True)
```

```ts
async function loadDreams(userIds: string[], window: TimeWindow): Promise<DigestDreamRow[]> {
  const [snaps, events] = await Promise.all([
    db
      .select({
        userId: personalitySnapshots.userId,
        capturedAt: personalitySnapshots.capturedAt,
        driftFromAnchor: personalitySnapshots.driftFromAnchor,
        driftFromPrev: personalitySnapshots.driftFromPrev,
      })
      .from(personalitySnapshots)
      .where(
        and(
          inArray(personalitySnapshots.userId, userIds),
          eq(personalitySnapshots.snapshotType, 'dream'),
          between(personalitySnapshots.capturedAt, window.from, window.to),
        ),
      ),
    db
      .select({ userId: agentEvents.userId, metrics: agentEvents.metrics, createdAt: agentEvents.createdAt })
      .from(agentEvents)
      .where(
        and(
          inArray(agentEvents.userId, userIds),
          eq(agentEvents.type, 'dream'),
          eq(agentEvents.outcome, 'success'),
          between(agentEvents.createdAt, window.from, window.to),
        ),
      )
      .orderBy(desc(agentEvents.createdAt)),
  ]);
  const diff = new Map<string, { before: string | null; after: string | null }>();
  for (const e of events) {
    if (diff.has(e.userId)) continue; // newest first
    const m = (e.metrics ?? {}) as Record<string, unknown>;
    diff.set(e.userId, {
      before: typeof m.recentBefore === 'string' ? m.recentBefore : null,
      after: typeof m.recentAfter === 'string' ? m.recentAfter : null,
    });
  }
  return snaps.map((s) => ({
    ...s,
    recentBefore: diff.get(s.userId)?.before ?? null,
    recentAfter: diff.get(s.userId)?.after ?? null,
  }));
}
```
