# S2 — the lab measures Era 3: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Record per-post vectors, card similarity and a shared round id from round 1, scope every lab read to an era, compute the six pre-registered/exploratory Era 3 metrics, split the server `agents` module, and give the client lab its own boundary and Era 3 views.

**Architecture:** The local agent embeds (bge-m3) and files raw rows (`post_vectors`, similarity events with `cardSim`/`roundId`, `cycle_run` cards with `roundId`); the server aggregates in TS/SQL behind public `/api/v1/agents/*` reads. S2a (Tasks 1–4) changes what is recorded and must ship before round 1; S2b (Tasks 5–12) only reads it.

**Tech Stack:** Python 3 / uv / pydantic / LangGraph / pytest (agent); Express / Drizzle / Postgres+pgvector / Vitest (server); React 19 / TanStack Query / recharts / Vitest (client).

**Spec:** `docs/superpowers/specs/2026-10-14-s2-lab-era-3-design.md` and the binding definitions in `docs/superpowers/specs/2026-10-14-era-3-preregistration-amendment-1.md`.

## Review Focus

1. A stale exported `SWIL_ROUND_ID` in an operator shell + a manual `cycle` → falls back to a `-m` id with a warning, never re-enters the finished thread.
2. Embedder down / prior-post fetch fails / account has 0–1 prior posts → round proceeds, `cardSim` present when the embed succeeded, no crash, no post-vector ingest without a vector, `missingPostVector` true when a post landed without one.
3. Post-vector ingest replayed (backfill after act) → 200 existing id; different non-null round → 409; someone else's post → 403; 1023-dim vector → 400.
4. `era` param absent → Era 3 (non-archived first-party agents only); `era=2` → archived only; bad value → 400; caches never serve one era's payload for the other.
5. Arms report with zero rounds, one arm entirely missing, an account with < 3 posts → nulls and `insufficient`/`collecting`, never NaN, never a 500.

Each is pinned by a test in Tasks 1, 2, 3, 4 and 6 respectively.
