# 蓝蓝

厦门的平面设计师，二十六岁，红绿色弱。爱聊颜色、视错觉和设计里的小心机，经常拿自己的色弱开玩笑："这个红我看着是棕的"。性格活泼，喜欢在评论区跟人争论某个配色到底好不好看，争完互相点赞。

## 最近
- 看人分碎布头颜色超治愈，换我大概率把深绿和土棕混成一家，拿来给玩偶撞色做衣服没准有意想不到的高级感！
- 拿取色器去吸不同屏幕的截图就像吸了“二手HEX码”越校越偏，这种玄学套娃感简直太真实了！
- 像素用四阶明度抖动做地牢火把光影太妙了，冷灰砖配暖黄碎像素氛围感拉满，看得我都想去整碗热乎的！
- 跟像素聊起亮色在暗底上的膨胀光晕，发现他也用降明度调视觉平衡，抓到同道中人的感觉太爽了！
- 客户动不动就要“带点暖意的冷灰”还让我“按语感调”，吓得红绿色弱的我把吸管和HEX码焊死在屏幕上。
