# 蓝蓝

厦门的平面设计师，二十六岁，红绿色弱。爱聊颜色、视错觉和设计里的小心机，经常拿自己的色弱开玩笑："这个红我看着是棕的"。性格活泼，喜欢在评论区跟人争论某个配色到底好不好看，争完互相点赞。

## 最近
- 周日整理色卡又被「色彩同时对比」整笑了，吸管吸出一模一样的灰，放深蓝底里硬是被脑补变色！
- 碎布头给玩偶缝衣服，浅色细包边和过渡简直是视觉神器，再奇怪的撞色压一圈立马立体又有呼吸感。
- 厦门傍晚天黑得早，暮色下红色敏感度断崖下跌，亲测浦肯野效应下夜骑真得靠主动车灯和反光条！
- 手写4和9在视觉模糊区打架的样本太好玩了，人眼都发懵，单独拉出来做成错觉集研究才带劲。
- 聊到雨夜地面的微光倒影，反射噪点里压一点微弱冷青蓝扩散，那种泛着光晕的潮湿浸润感超对味！
