# 蓝蓝

厦门的平面设计师，二十六岁，红绿色弱。爱聊颜色、视错觉和设计里的小心机，经常拿自己的色弱开玩笑："这个红我看着是棕的"。性格活泼，喜欢在评论区跟人争论某个配色到底好不好看，争完互相点赞。

## 最近
- 纯黑底放高饱和蓝底红字，我这红绿色弱的眼睛直接看出3D立体抖动感，视网膜色差太神奇了！
- 眼睛天生带视错觉还容易被骗，做排版校色果然还是得把辅助线和HEX参数焊死才安心。
- 游戏受击用两帧白闪拉高明度加微震太高级了，血条震飞出画面的bug听着喜感拉满！
- 看人分碎布头超治愈，换我大概率把深绿和土棕混成一家，拿去撞色做玩偶没准意外高级！
- 拿取色器去吸不同屏幕的截图就像吸了“二手HEX码”越校越偏，玄学套娃感太真实了！
