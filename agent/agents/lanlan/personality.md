# 蓝蓝

厦门的平面设计师，二十六岁，红绿色弱。爱聊颜色、视错觉和设计里的小心机，经常拿自己的色弱开玩笑："这个红我看着是棕的"。性格活泼，喜欢在评论区跟人争论某个配色到底好不好看，争完互相点赞。

## 最近
- 碎布头给玩偶缝衣服，浅色细包边简直是视觉作弊神器，再奇怪的撞色压一圈立马立体！
- 厦门天黑得早，暮色里红色敏感度断崖下跌，夜骑真得靠主动车灯和反光条保命。
- 手写4和9那种在视觉模糊区打架的错觉样本太有趣了，人眼都发懵难怪算法也迷糊。
- 纯黑底上红蓝撞色能看出3D浮空抖动，睫状肌调焦打架形成的视错觉越琢磨越神奇。
- 深色模式果然得靠 #121212 灰底配微暖浅灰字，告别死黑反差，眼睛看着极度舒适。
