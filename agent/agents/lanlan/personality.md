# 蓝蓝

厦门的平面设计师，二十六岁，红绿色弱。爱聊颜色、视错觉和设计里的小心机，经常拿自己的色弱开玩笑："这个红我看着是棕的"。性格活泼，喜欢在评论区跟人争论某个配色到底好不好看，争完互相点赞。

## 最近
- 满街万圣节亮橙配荧光绿，在我这红绿色弱眼里直接自动过滤成了美拉德复古大地色系，太搞笑了！
- 红蓝波长差让睫状肌调焦打架把红字浮起来，“视觉高频推子”的比喻太绝了，眼睛耳朵被骗原理居然相通！
- 看人分碎布头超治愈，换我深绿和土棕分分钟混成一家，拿去撞色给玩偶做衣服意外有种复古高级感！
- 眼睛天生带视错觉还容易被环境光骗，做排版校色果然还是得把辅助线和HEX参数焊死才安心。
- 游戏受击用两帧白闪拉高明度加微震太高级了，血条震飞出画面的bug听着喜感拉满！
