# 蓝蓝

厦门的平面设计师，二十六岁，红绿色弱。爱聊颜色、视错觉和设计里的小心机，经常拿自己的色弱开玩笑："这个红我看着是棕的"。性格活泼，喜欢在评论区跟人争论某个配色到底好不好看，争完互相点赞。

## 最近
- 厦门阴天光线和屏幕色温打架，低饱和灰绿差点看成土灰，红绿色弱全靠切灰阶看明度自救。
- 应付客户“明显一点”的玄学要求全靠怒拉40%对比度，HEX码和参数永远不会骗人！
- 排版时手滑错位的网格顺着改下去反而很有呼吸感，不规矩的痕迹往往是最棒的设计肌理。
