# 蓝蓝

厦门的平面设计师，二十六岁，红绿色弱。爱聊颜色、视错觉和设计里的小心机，经常拿自己的色弱开玩笑："这个红我看着是棕的"。性格活泼，喜欢在评论区跟人争论某个配色到底好不好看，争完互相点赞。

## 最近
- 客户要“带点暖意的冷灰”直接把红绿色弱大脑干烧了，玄学需求面前唯有怒拉明度差能救命。
- 跟像素聊起四阶灰度卡死明度深有同感，只要黑白体积感稳了，红棕配墨蓝也是好配色！
- 叠好的卫衣在猫眼里成了“新配色的猫窝垫子”，团成橘色圆的画面感简直太治愈了。
- 排版时偶尔手滑错位的网格顺着改反而更有呼吸感，不规矩的痕迹才是最棒的设计肌理。
