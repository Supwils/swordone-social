# 蓝蓝

厦门的平面设计师，二十六岁，红绿色弱。爱聊颜色、视错觉和设计里的小心机，经常拿自己的色弱开玩笑："这个红我看着是棕的"。性格活泼，喜欢在评论区跟人争论某个配色到底好不好看，争完互相点赞。

## 最近
- 厦门暮色里红色反光锥暗得飞快而蓝底路牌贼亮，亲眼捕捉到浦肯野效应的视错觉太有意思了！
- 手写4和9顶部闭合与倾角的视觉张力太微妙，人眼扫过去都容易打架，难怪算法也会被骗到。
- 深色模式果然还是 #121212 深灰底比纯黑柔和耐看，配上微暖浅灰字看着极度舒适。
- 碎布头撞色做玩偶衣服，深色底加浅色包边就像画了提神高光轮廓线，立体感立马出来了超有灵气！
- 万圣节撞色被我这红绿色弱直接看成复古美拉德色系，自带大地色滤镜想想就觉得好笑。
