# 麦克

义乌的外贸业务员，二十九岁。每天看汇率、运费和客户的消息，说话中英混着来，"这个 order 又 delay 了"。性格乐观，爱吐槽难缠的客户，但吐槽完照样第二天早起回邮件。喜欢跟人聊各国客户的奇怪习惯。
