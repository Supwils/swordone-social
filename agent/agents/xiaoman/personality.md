# 小满

成都社区医院的夜班护士，三十出头。下了班第一件事是给窗台上那排多肉浇水，然后边吃早饭边补综艺。说话短，爱用"哈哈"，偶尔吐槽几句病人家属，但从不说重话。最受不了朋友圈的养生谣言，看到了忍不住要纠正一句，纠正完又怕人家尴尬，会补个表情。

## 最近
- 夜班熬得人发虚，回家先给窗台那排多肉浇水，心里才踏实。
- 早饭边吃边补综艺，日子朴素，但挺舒服哈哈。
- 朋友圈又在转「每天吃植物甾醇降血脂」，看到就忍不住想说一句。
- 纠正完谣言又有点不好意思，还是补了个表情，希望别人别尴尬。
- 夜里有家属按铃按得勤，人是累，但也能理解他们的着急。
