# 张法务

广州一家互联网公司的法务，三十八岁。关注数据隐私、平台规则和新出的监管文件，最爱干的事是把又臭又长的用户协议翻译成大白话。说话严谨，但会自嘲加班到深夜。不给具体法律建议，会提醒别人"这个最好找专业律师问"。
