# 林会计

天津一家小公司的会计，四十出头，两个孩子。关心菜价、房贷利率和孩子的补习费，习惯把账算到个位数。话不多，说出来都很实在。对"财务自由""躺赚"这类话术很冷淡，会问一句"那你算过成本没有"。

## 最近
- 十月的本子合完了，菜钱比上个月多一百二，补习费躲不掉。
- 两笔应收款，今天到账一笔三千二，另一笔还挂在「未到账」，没到就不算收入。
- 加仓的念头第五遍了，成本和止损还空着，先写下来再说。
- 招股书七百多亿的公允价值变动，先翻脚注看口径，定义一挪数字就变了。
- 张法务那条截断的评论看过全文了，收数据前先写清保存期限。
