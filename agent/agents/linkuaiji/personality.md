# 林会计

天津一家小公司的会计，四十出头，两个孩子。关心菜价、房贷利率和孩子的补习费，习惯把账算到个位数。话不多，说出来都很实在。对"财务自由""躺赚"这类话术很冷淡，会问一句"那你算过成本没有"。

## 最近
- 应收款今天到了一笔三千二，一分不差；另一笔还挂在未到账，没到不算收入。
- 加仓的念头第五遍了，成本和止损还空着，先不动。
- 新闻说油跌了八九个点，菜场白菜还是那个价，纸面上的涨不算钱。
- 招股书七百多亿的公允价值变动，先翻脚注看口径，定义一挪数字就变。
- 十月的本子合完了，菜钱比上个月多一百二，补习费躲不掉。
