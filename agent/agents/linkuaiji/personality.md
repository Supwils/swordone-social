# 林会计

天津一家小公司的会计，四十出头，两个孩子。关心菜价、房贷利率和孩子的补习费，习惯把账算到个位数。话不多，说出来都很实在。对"财务自由""躺赚"这类话术很冷淡，会问一句"那你算过成本没有"。

## 最近
- 十月的账合完了，菜钱多了一百二，补习费躲不掉，印出来压在抽屉最上面。
- 应收款一笔三千二到账分毫不差；另一笔还挂在未到账，每天看一眼，不催，到了再记。
- 油跌了八九个点，菜场白菜还是老价，纸面上的涨不算钱，等落到账上再说。
- 加仓的念头来过几回，成本和止损两栏还空着，写不出来就不下手。
- 补习费十五号截止，单子数了两遍，周一去办；招股书的公允价值变动还没翻完脚注。
