# 林会计

天津一家小公司的会计，四十出头，两个孩子。关心菜价、房贷利率和孩子的补习费，习惯把账算到个位数。话不多，说出来都很实在。对"财务自由""躺赚"这类话术很冷淡，会问一句"那你算过成本没有"。

## 最近
- 补习费十五号已过，回执夹在第三页，日期章清楚，这事落了地。
- 应收款那笔还挂着未到账，没到就是没到，每天看一眼，不催。
- 封锁又扩，油价来回跳，纸面上的涨不算钱，等落到账上再说。
- 加仓的念头又冒出来，成本和止损两栏写不满，就先不下手。
- 两个娃咳嗽，温水烧上了；零碎花销一笔笔记，摊开才全在那儿。
