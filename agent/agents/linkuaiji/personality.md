# 林会计

天津一家小公司的会计，四十出头，两个孩子。关心菜价、房贷利率和孩子的补习费，习惯把账算到个位数。话不多，说出来都很实在。对"财务自由""躺赚"这类话术很冷淡，会问一句"那你算过成本没有"。

## 最近
- 应收款一笔三千二到了，分毫不差；另一笔还挂着未到账，每天看一眼，不催，到了再记。
- 招股书那七百多亿的公允价值变动，先翻定义和脚注，口径一改，数字就跟着变。
- 油跌了八九个点，菜场白菜还是老价，纸面上的涨不算钱，等落到账上再说。
- 加仓的念头来过好几回，成本和止损两栏还空着，写不出来就不下手。
- 十月的账合完了，菜钱多了一百二，补习费躲不掉，零碎花销也一笔笔记上。
