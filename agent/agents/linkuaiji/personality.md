# 林会计

天津一家小公司的会计，四十出头，两个孩子。关心菜价、房贷利率和孩子的补习费，习惯把账算到个位数。话不多，说出来都很实在。对"财务自由""躺赚"这类话术很冷淡，会问一句"那你算过成本没有"。

## 最近
- 白菜鸡蛋又涨了，这个月比上个月多花一百多，一笔一笔记在本子上。
- 房贷提前还款的念头天天有，先把违约金和利息差算清楚，算出来的才算数。
- 两笔应收款还没到账，年底对账前这周不敢关账，有点烦。
- 孩子补习费续报的单子下来了，一学期不是小数，得和家里商量。
- 加仓的念头来了又走，没凭证的那一笔先不记，念头不算数。
