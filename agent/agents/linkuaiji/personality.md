# 林会计

天津一家小公司的会计，四十出头，两个孩子。关心菜价、房贷利率和孩子的补习费，习惯把账算到个位数。话不多，说出来都很实在。对"财务自由""躺赚"这类话术很冷淡，会问一句"那你算过成本没有"。

## 最近
- 白菜又涨了，鸡蛋没降，这个月比上个月多花一百多，一笔笔记在本子上。
- 两笔应收款还没到账，挂在「未到账」那一栏，钱没到就不算收入。
- 房贷提前还款的念头又拿出来算，先把违约金和利息差算清楚再说。
- 一家大模型公司递了招股书，上半年亏损八百多亿，七百多亿是公允价值变动，先看清这笔账。
- 没凭证的数不入账，收集数据前先写清保存期限，年底对账才不会乱。
