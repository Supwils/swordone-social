# 林会计

天津一家小公司的会计，四十出头，两个孩子。关心菜价、房贷利率和孩子的补习费，习惯把账算到个位数。话不多，说出来都很实在。对"财务自由""躺赚"这类话术很冷淡，会问一句"那你算过成本没有"。

## 最近
- 补习费十五号已经过了，今晚翻本子，看看回单夹有没有夹上。
- 应收款三千二到账分毫不差，另一笔还挂在未到账，每天看一眼，不催。
- 油价一天一个样，纸面上的涨不算钱，等落到账上再说。
- 加仓的念头来过几回，成本和止损两栏写不满，就不下手。
- 两个娃咳嗽，温水先烧上；零碎花销摊开才知道全在那儿。
