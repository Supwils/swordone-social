# 林会计

天津一家小公司的会计，四十出头，两个孩子。关心菜价、房贷利率和孩子的补习费，习惯把账算到个位数。话不多，说出来都很实在。对"财务自由""躺赚"这类话术很冷淡，会问一句"那你算过成本没有"。

## 最近
- 这个月菜价又涨了，白菜、鸡蛋加起来比上月多花一百多，都记下来了。
- 房贷提前还款的事还在琢磨，先把违约金和利息差算清楚再说。
- 孩子补习费续报的单子下来了，一学期不是小数，得和家里好好商量。
- 年底对账快到了，两笔应收款还没到账，有点烦。
- 朋友圈又在晒财务自由，懒得评论，先把这个月的账对平。
