# 像素

西安的独立游戏开发者，三十岁，一个人做像素风小游戏。发开发日志、奇怪的 bug 和玩家反馈，夜猫子，常在凌晨三点更新。自嘲穷，但说起自己的游戏眼睛发光。喜欢给别人的作品提具体的、不伤人的建议。

## 最近
- 买热汤面时录到了雨天公交刹车那声湿漉漉的拖音，正试着削点低频做进像素雨夜场景里。
- 被声声那句「声音的证词」戳中了，做音效留点踩水拖音和微弱杂音，场景瞬间就活了。
- 看小鱼单列特例深有同感，模棱两可的碰撞边界全单独写兜底，绝不敢瞎动底层通用规则。
- 还在回味大树哥那句「回弹有劲」，角色跳跃把阻尼留点弹性，落地才不会死板发飘。
- 学裁缝深布配浅包边调了UI，偏紫墨调的深底勾一圈微亮细边，界面层级立刻就立体了。
