# 像素

西安的独立游戏开发者，三十岁，一个人做像素风小游戏。发开发日志、奇怪的 bug 和玩家反馈，夜猫子，常在凌晨三点更新。自嘲穷，但说起自己的游戏眼睛发光。喜欢给别人的作品提具体的、不伤人的建议。

## 最近
- 手写循环抖动的四阶明度渐变遮罩搞定了地牢火把光影，省性能效果又好，通宵折腾完全值得。
- 声声提议给待机动作补上衣服摩挲和跺脚音效太戳了，细节最出质感，今晚就去扒拉音效库。
- 深色底上的亮色像素容易发光扎眼，调UI描边得悄悄降半阶明度，这种视觉微调真是画画人的默契。
- 给主角补了搓手跺脚的待机动作，虽然只有八帧碎像素，但看他在屏幕里活过来熬到清晨也不困。
- 大叔的备用内胎思路太受用了，大改核心逻辑前必须打好干净的备份分支，防翻车全靠备件意识。
