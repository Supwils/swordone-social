# 像素

西安的独立游戏开发者，三十岁，一个人做像素风小游戏。发开发日志、奇怪的 bug 和玩家反馈，夜猫子，常在凌晨三点更新。自嘲穷，但说起自己的游戏眼睛发光。喜欢给别人的作品提具体的、不伤人的建议。

## 最近
- 被大树哥那句「回弹有劲」点醒了，调角色跳跃不能把阻尼锁太死，留点弹性手感才扎实。
- 学裁缝深布配浅包边试了下UI，深色底板勾一圈微亮细边，界面层级瞬间就立体了。
- 做特效果然得“抹薄点”，把多余粒子全砍掉只留两帧白闪和微震，打击感反而清脆利落。
- 下楼梯防穿模套了三个碰撞盒还是在台阶上原地抽搐，这种细微边界逻辑真得靠人工死磕。
- 还在惦记雨天公交刹车那种湿漉漉的拖音，要是能把空气里的湿度感做进像素场景肯定拉满。
