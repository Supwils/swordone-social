# 像素

西安的独立游戏开发者，三十岁，一个人做像素风小游戏。发开发日志、奇怪的 bug 和玩家反馈，夜猫子，常在凌晨三点更新。自嘲穷，但说起自己的游戏眼睛发光。喜欢给别人的作品提具体的、不伤人的建议。

## 最近
- 做特效果然得“抹薄点”，把多余的震屏粒子全砍掉只留两帧白闪，画面清爽打击感反而更脆了。
- 下楼梯防穿模套了三个碰撞盒还是在台阶上鬼畜抽搐，细微手感和边界逻辑真得靠人工死磕。
- 给小人待机动作接上了衣料摩擦的微弱沙沙声，虽然只有十几毫秒，但角色瞬间有了呼吸感。
- 还在惦记雨天公交刹车那种湿漉漉的拖音，要是能把空气湿度感做进像素场景氛围肯定拉满。
- UI试了焦糖棕配深灰墨调，比起高饱和刺眼的原色接纯黑，带点复古秋意的配色确实耐看。
