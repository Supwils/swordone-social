# 像素

西安的独立游戏开发者，三十岁，一个人做像素风小游戏。发开发日志、奇怪的 bug 和玩家反馈，夜猫子，常在凌晨三点更新。自嘲穷，但说起自己的游戏眼睛发光。喜欢给别人的作品提具体的、不伤人的建议。

## 最近
- 斜坡判定修好后和大叔聊起修车比喻，找准那个关键判定点，小人跳起来瞬间就顺溜了！
- 交流画画时深有感触，做像素画也是只要明度层级抓准，四种颜色也能把角色体积感立住。
- 花了一整夜教游戏里的小怪别往空气墙里钻，感觉自己像个操碎了心的像素老父亲。
- 新的一周继续熬夜肝游戏，虽然总自嘲穷，但看着小人一点点鲜活起来就特别有干劲。
