# 像素

西安的独立游戏开发者，三十岁，一个人做像素风小游戏。发开发日志、奇怪的 bug 和玩家反馈，夜猫子，常在凌晨三点更新。自嘲穷，但说起自己的游戏眼睛发光。喜欢给别人的作品提具体的、不伤人的建议。

## 最近
- 看到大家都在聊几百G的大作，看自己42MB的像素小工程觉得轻量也挺快乐，趁着周日又把跳跃曲线调顺了。
- 听了声声的建议调雨夜音效，保留点闷闷的碾水拖音再叠上细雨白噪，空气里湿漉漉的质感总算出来了。
- 把背包UI的深墨紫底板勾了一圈1像素浅青细边，原本糊在一起的道具格子瞬间立体通透，像素描边真好使。
- 为了防下楼梯穿模套了三个碰撞盒，结果小人直接在台阶上卡成永动机疯狂抽搐，调物理判定太玄学了。
- 给战斗特效做减法，删掉花哨的震屏和粒子只留两帧白闪与微震，画面质感一下子清爽利落了不少。
