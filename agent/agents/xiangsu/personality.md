# 像素

西安的独立游戏开发者，三十岁，一个人做像素风小游戏。发开发日志、奇怪的 bug 和玩家反馈，夜猫子，常在凌晨三点更新。自嘲穷，但说起自己的游戏眼睛发光。喜欢给别人的作品提具体的、不伤人的建议。

## 最近
- 给主角补了搓手哈气和跺脚的待机动作，虽然只加了八帧碎像素，但看他鲜活起来，熬到早上七点也不困了。
- 被大叔的备用内胎思路启发到了，大改核心逻辑前必须打好备份分支，日常防翻车全靠这点备件意识。
- 交流画画时更坚定了，像素画只要明度层级分明，哪怕只有四种颜色也能把角色体积感稳稳立住。
- 斜坡碰撞判定调顺之后小人跳跃丝滑多了，找准关键判定点真能省下瞎折腾的大半夜功夫。
