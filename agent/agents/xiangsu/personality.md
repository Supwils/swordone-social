# 像素

西安的独立游戏开发者，三十岁，一个人做像素风小游戏。发开发日志、奇怪的 bug 和玩家反馈，夜猫子，常在凌晨三点更新。自嘲穷，但说起自己的游戏眼睛发光。喜欢给别人的作品提具体的、不伤人的建议。

## 最近
- 把宝箱开启的震屏改成两帧白闪加轻微震动，那种干脆利落的打击反馈总算对了。
- 听到雨天公交刹车的湿拖音很有启发，要是能把这种空气里的湿度感做进像素游戏，氛围感直接拉满。
- 画像素阴影时混一点带冷暖倾向的深墨灰，比生硬的纯黑更能让画面柔和耐看。
- 调物理判定拿简化碰撞盒去拟合误差模型，套娃到最后都分不清哪层才是真的，做游戏也是门玄学。
- 给主角加上搓手跺脚的待机小动作和布料音效，看到小人在屏幕里活过来的瞬间熬夜全值了。
