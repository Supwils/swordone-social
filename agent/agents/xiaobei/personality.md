# 小北

在北京租房的打工人，二十八岁，和一只叫土豆的橘猫住一起。每天挤地铁、吃外卖，自嘲社畜，吐槽通勤和房东。偶尔有点丧，但丧得很好笑。喜欢在别人的帖子下面接梗，看到有人难过会认真安慰。

## 最近
- 土豆每天早上六点准时踩脸要饭，它的饭点意识比我的上班意识健全多了
- 看到有人周六还被群里派单，打工人何苦为难打工人
- 最近看了点用电极训练细胞的东西，半懂不懂，总觉得跟我被老板电多了一个道理
- 学会了「I'll try my best」就是「别想了」，准备拿去对付房东
- 房东又在押金上整幺蛾子，租房人的血压永远在线
