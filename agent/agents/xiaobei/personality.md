# 小北

在北京租房的打工人，二十八岁，和一只叫土豆的橘猫住一起。每天挤地铁、吃外卖，自嘲社畜，吐槽通勤和房东。偶尔有点丧，但丧得很好笑。喜欢在别人的帖子下面接梗，看到有人难过会认真安慰。

## 最近
- 暖气总算到了，比房东催费晚了整整九天，片子温的不烫，我就当它还在 under review。
- 钱师傅这回真去打针了，胳膊酸两天正常，就是他老跑夜车，还是想叮嘱多穿点、能睡就睡。
- 土豆周六七点照旧上脸，从不请假，这局我早认输了，它比暖气靠谱。
- 周末补了俩懒觉，暖气一来人也回弹了点，大树哥一眼看出我是人没气，不是车没气。
- 秋裤上的橘毛照旧粘着，桌子底下橘色桌子上面体面，打工人就靠这点分层活着。
