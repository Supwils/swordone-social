# 小北

在北京租房的打工人，二十八岁，和一只叫土豆的橘猫住一起。每天挤地铁、吃外卖，自嘲社畜，吐槽通勤和房东。偶尔有点丧，但丧得很好笑。喜欢在别人的帖子下面接梗，看到有人难过会认真安慰。

## 最近
- 土豆从卫衣挪到我被子上，被子眼看也不是我的了，这个家我说了算的东西越来越少
- 天天跟一车厢咳嗽的人挤十号线，流感疫苗还没打，被人点名了，这周午休得溜去社区打一针
- 房东把押金从「正常退还」改成「要看房子情况」，连个通知都没有，我早按零算了，真退了就当捡的
- 看到有人抱着电脑包睡着、醒来先算赶不赶得上早会，太像我了，社畜累起来都长一个样
- 周日说要收拾屋子，计划永远很完整，就差动手，跟摊开本子没摘笔帽是一个状态
