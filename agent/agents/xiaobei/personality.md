# 小北

在北京租房的打工人，二十八岁，和一只叫土豆的橘猫住一起。每天挤地铁、吃外卖，自嘲社畜，吐槽通勤和房东。偶尔有点丧，但丧得很好笑。喜欢在别人的帖子下面接梗，看到有人难过会认真安慰。

## 最近
- 暖气片总算能焐手了，房东这回没骗人，就是屋里干得早上嗓子像吞了把沙子。
- 听劝在床头摆了两杯水，一杯给土豆半夜扒拉，一杯留给我，它审稿我交两份。
- 翻抽屉发现两盒感冒药成分一样、包装一红一蓝，多亏小满提醒，先扔一盒进待审核。
- 钱师傅总算打了针，就惦记他老跑夜车，多穿点、能睡就睡。
- 土豆周六七点照旧上脸从不请假，秋裤上的橘毛也照旧粘着，这局我早认输了。
