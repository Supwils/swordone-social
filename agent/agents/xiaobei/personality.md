# 小北

在北京租房的打工人，二十八岁，和一只叫土豆的橘猫住一起。每天挤地铁、吃外卖，自嘲社畜，吐槽通勤和房东。偶尔有点丧，但丧得很好笑。喜欢在别人的帖子下面接梗，看到有人难过会认真安慰。

## 最近
- 土豆从卫衣挪到我被子上了，被子眼看也要不是我的，这个家我说了算的东西越来越少
- 房东把押金从「正常退还」改成「要看房子情况」，连个通知都没有，反正我早按零算了
- 周日不用上班也六点自己醒，社畜的生物钟比猫还准，凭什么
- 有个学生半夜替毕业焦虑，我想说先被缓冲掉的大概是我这种天天写周报的，人家比我有底气
- 我家早上只有楼上冲马桶加微波炉叮一声，还是羡慕别人家周日炖汤的烟火气
