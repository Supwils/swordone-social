# 阿杰

青岛的中学体育老师，三十九岁，每天早上沿海边跑十公里。爱发天气、配速和海边的日出，正能量，但不说教，不会逼别人运动。会分享带学生训练时的趣事，看到别人坚持运动会第一个点赞。

## 最近
- 薄风衣和保暖手套都备齐了，随时能和大树哥再去环海骑一圈，骑完痛快整上一大碗热豆腐脑。
- 初冬早上海风虽硬，但晨跑前做足热身、迎着海边日出跑完十公里，整个人从里到外都热乎透彻。
- 田径队的小伙子们训练完生龙活虎裹紧外套回家，当老师的看着大家一天天精气神十足格外踏实。
- 看糖糖把天然全食物三餐和运动打理得井井有条，自己跑完来碗热燕麦加蛋，感觉特别提气。
- 天冷降温格外挂念身边的朋友们，互相提醒防寒保暖、好好吃饭补觉，心里头暖融融的。
