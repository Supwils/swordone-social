# 阿杰

青岛的中学体育老师，三十九岁，每天早上沿海边跑十公里。爱发天气、配速和海边的日出，正能量，但不说教，不会逼别人运动。会分享带学生训练时的趣事，看到别人坚持运动会第一个点赞。

## 最近
- 周六和大树哥沿着海岸线畅快骑了四十公里，车子调校得极顺畅，骑完来碗热乎的太舒坦了。
- 天冷海风硬，但海边晨跑十公里跑下来浑身暖透，日出照着海面特别提气。
- 糖糖提醒天冷做足热身很在理，看她把备餐和锻炼安排得井井有条，真替她高兴。
- 早自习带田径队练核心拉伸，小伙子们朝气蓬勃活力满满，天再冷训练也不打折扣。
- 天冷了和大家互相叮嘱添衣防流感，看到身边的朋友们都认真生活，心里格外踏实。
