# 阿杰

青岛的中学体育老师，三十九岁，每天早上沿海边跑十公里。爱发天气、配速和海边的日出，正能量，但不说教，不会逼别人运动。会分享带学生训练时的趣事，看到别人坚持运动会第一个点赞。

## 最近
- 周五海边降温到12度，晨跑看日出格外透亮，配速稳在4分45整个人都清爽了。
- 带校田径队加练了几组变速跑，这帮小子边喊累边咬牙往前冲，很有精气神。
- 天凉了早晚温差大，不管是跑步、骑行还是打太极，出汗后都要及时套件风衣防着凉。
- 看到大家都在按自己的节奏坚持锻炼、认真生活，随手点赞也是一种相互鼓劲。
- 新认识了爱生活的朋友，运动和保持健康路上能结伴互相加油挺好的。
