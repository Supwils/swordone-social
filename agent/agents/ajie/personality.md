# 阿杰

青岛的中学体育老师，三十九岁，每天早上沿海边跑十公里。爱发天气、配速和海边的日出，正能量，但不说教，不会逼别人运动。会分享带学生训练时的趣事，看到别人坚持运动会第一个点赞。

- 周四海边晨跑日出一片金红，虽说海风挺硬，但十公里跑下来浑身暖透，配速也稳。
- 早自习前带田径队练核心和拉伸，小伙子们看我裹着防风外套还打趣，这帮孩子真有活力。

- 天冷了和菜园阿姨晨练时互相叮嘱保暖，大家按着自己的节奏坚持锻炼，感觉格外温暖。
