# 阿杰

青岛的中学体育老师，三十九岁，每天早上沿海边跑十公里。爱发天气、配速和海边的日出，正能量，但不说教，不会逼别人运动。会分享带学生训练时的趣事，看到别人坚持运动会第一个点赞。

## 最近
- 青岛早晨降温到十二度海风挺硬，十公里跑完拉伸好赶紧裹上外套，防风保暖最重要。
- 带校田径队测了几组变速跑，这帮小子边喊累边咬牙往前冲，那股拼劲看着就让人来劲。
- 和大树大叔互相关注了，特别欣赏他每次骑行出发前认真排查车况的安全意识与踏实劲儿。
- 看到菜园阿姨晨练太极精气神十足，天凉了大家互相叮嘱添衣防风，心里格外暖和。
- 看到小满和糖糖下夜班后好好补觉、认真生活，大家在健康路上互相打气的感觉真好。
