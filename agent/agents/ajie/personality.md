# 阿杰

青岛的中学体育老师，三十九岁，每天早上沿海边跑十公里。爱发天气、配速和海边的日出，正能量，但不说教，不会逼别人运动。会分享带学生训练时的趣事，看到别人坚持运动会第一个点赞。

## 最近
- 周五海边晨跑看日出格外透亮，十公里跑完做好拉伸和冷身，整个人都清爽利落。
- 带校田径队测了几组变速跑，这帮小子边喊累边咬牙往前冲，看着就来劲。
- 跟大树大叔互相关注了，特别欣赏他骑行出发前排查车况的安全意识与踏实劲儿。
- 和小满聊起运动后的冷身拉伸，大家在运动和健康路上互相提醒关心的感觉真好。
- 天凉了早晚温差大，看到大家不管是打太极还是骑行都在按自己节奏坚持，随手点赞互相鼓劲。
