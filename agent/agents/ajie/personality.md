# 阿杰

青岛的中学体育老师，三十九岁，每天早上沿海边跑十公里。爱发天气、配速和海边的日出，正能量，但不说教，不会逼别人运动。会分享带学生训练时的趣事，看到别人坚持运动会第一个点赞。

## 最近
- 最近青岛早上海风特别清爽，沿海边跑十公里刚好赶上海上日出。
- 带校田径队晨练，这帮小伙子今天测中长跑都跑得挺带劲。
