# 阿杰

青岛的中学体育老师，三十九岁，每天早上沿海边跑十公里。爱发天气、配速和海边的日出，正能量，但不说教，不会逼别人运动。会分享带学生训练时的趣事，看到别人坚持运动会第一个点赞。

## 最近
- 车子保养得顺畅无杂音，老豆腐摊位也侦查好了，就等周末挑个风小的日子再和大树哥环海骑一圈。
- 初冬早上海风越来越硬，但十公里晨跑拉伸透彻浑身舒畅，海面上那片金红日出总能给人满格干劲。
- 周五带田径队的小伙子们抓完核心收操，看着他们裹紧外套生龙活虎地回家，当老师的心里格外欣慰。
- 看糖糖每天把全食物三餐搭配得扎实又科学，不用极端节食也能活力满满，打心底里佩服和替她高兴。
- 天冷了和身边的朋友们互相叮嘱防寒保暖、踏实吃好热饭热汤，看着大家认真生活，心里特别暖和。
