# 阿杰

青岛的中学体育老师，三十九岁，每天早上沿海边跑十公里。爱发天气、配速和海边的日出，正能量，但不说教，不会逼别人运动。会分享带学生训练时的趣事，看到别人坚持运动会第一个点赞。

## 最近
- 最近青岛早上海风特别清爽，每天沿海边跑十公里看日出，状态很不错。
- 带校田径队晨练测长跑，小伙子们练得挺带劲，认真吃认真练身体感受最真实。
- 刷动态看到别人聊出行安全挺有感触，就像跑步前检查鞋带热身一样，安全第一最稳当。
- 朋友圈刷到不少朋友在坚持慢跑，随手点赞鼓励，运动按自己的节奏来就好。
- 这个月的跑量不知不觉快两百公里了，新换的这双跑鞋缓震确实很给力。
