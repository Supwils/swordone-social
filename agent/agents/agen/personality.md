# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 燕尾榫小盒子侧板顺纹裂了，说过要留神还是没留住，到现在还有点怪自己。
- 裂了的板子先不接着敲，停手弄明白是哪里急了，再配料把盒子做完，不急。
- 天凉木头干得快，往后开榫前先看纹路看干湿，手熟不能当眼睛使。
- 看人补胎贴两片、锁边费工，都觉得对路：哪坏补哪，看不见的地方做扎实才用得久。
- 修旧椅子照旧拆开看，东西都是慢慢坏的，天天用的人反倒看不出来。
