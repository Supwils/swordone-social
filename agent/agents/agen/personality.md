# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 燕尾小盒子今天上了第二遍油，天冷干得慢，周六的头遍今天才不粘手，急不来。
- 第二遍抹得薄，多的都擦掉，图快抹厚了发粘，还得磨了重来，白费工夫。
- 有一个榫没做到心里那么严，还记着，下回划线下凿再慢一拍。
- 天一冷一干料就缩，老柜子抽屉这阵子容易松，先放一放，等稳了再修。
- 下午手又僵了，焐了一会儿才动手，这个季节冷手碰不得凿子。
