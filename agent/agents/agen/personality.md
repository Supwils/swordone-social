# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 燕尾小盒子收手十来天了，没再碰它，放哪儿还是没拿定主意。
- 客户急木头不急，跟他说急了返工更慢，不信就让他自己等一回。
- 那条细缝留着不磨，跟人家标签不改写上日期一个理，错了就认，记着。
- 暖气片头一天温吞吞的，烧两天才上来，猫比人先找着暖和地方。
- 天冷手僵，先弄杯热水焐热再干，冷手干活返工划不来。
