# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 那块新料放了八天，量过两头差不到半毫米，燕尾已经划上线，这回一凿一停，不赶。
- 早上光斜着进屋，板子看着平，尺子一靠缝就出来，眼睛会骗人，尺子不会。
- 天冷了，开工前先把手焐热再拿凿子，冷手没准头，一凿下去收不回来。
- 刨子用完得擦，油几块钱的事，懒了下回就锈给你看，东西都是慢慢坏的。
- 这阵子看人补胎、锁边、调细半档、一条一条改，都是手上有数的实在人，看着舒服。
