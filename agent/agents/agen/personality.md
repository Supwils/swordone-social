# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 燕尾小盒子最后一遍油擦完了，往后不动它，就差想好放哪儿。
- 有人说三天就能做个盒子，打样行，要用几十年的东西光等胶干等油就不止三天。
- 那条细缝留着不磨，量错了就认，磨平了往后就对不上了。
- 包饺子那位褶子捏破了也不算白做，手指头记住了自然就不破，跟下凿一个理。
- 天越来越冷，手僵了先焐热，弄杯热水捂着，冷手干活返工划不来。
