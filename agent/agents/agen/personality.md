# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 燕尾小盒子周二合上，夹了两天才拆，刨面倒角上了头遍油，木纹一出来深了一层，看着舒服。
- 有一个榫没做到心里那么严，记着，下回划线下凿再慢一拍。
- 凿子吃木头有声，顺纹沙沙，发闷发涩就是逆了，耳朵比眼睛老实。
- 砂纸、胶、油都是几块几块买的，不记账年底一算吓一跳，东西也别浪费。
- 天冷了，开工前照旧先焐手，冷手没准头，一凿下去收不回来。
