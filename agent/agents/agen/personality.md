# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 燕尾榫盒子侧板裂的那道缝过去快一礼拜了，还搁在心上，那回是手急了，得认。
- 新下的料在屋里放了快一礼拜，今天拿尺子量一遍，再开榫，把那个盒子做完。
- 天凉木头干得快，眼睛看着顺不算数，量过了心里才踏实。
- 这阵子看人补胎、锁边、调细半档，都是手上有数的实在人，看着舒服。
- 凿子要收得住，人也一样，干活手上得有个停顿，不能一口气往下赶。
