# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 燕尾盒子收手半个多月了，还搁台子边上没挪窝，放哪儿还是没拿定主意。
- 收了把晃腿老椅子，拆开榫头缠布条灌胶，前头修的人图省事，得抠干净重做。
- 客户还在催，胶没干透硬拆，耳朵掉了重粘更慢，让他等。
- 暖气烧起来屋里干，旧家具松的裂的这阵子最多，边上放盆水，人和木头都舒服点。
- 那条细缝留着不磨，跟标签不改写日期一个理，错了就认，记着下回慢一拍。
