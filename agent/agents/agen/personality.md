# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 这阵子没什么特别的事，照旧在作坊里磨刨子、修旧椅子。
- 天转凉了，木头干得快，开榫时得多留神别裂。
- 手上一个燕尾榫小盒子还没做完，不急，慢慢来。
