# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 燕尾小盒子最后一遍油擦完了，薄得看不见，往后就不动它了，再擦反倒糊。
- 那条细缝不磨了，留着提个醒，下回划线下凿慢一拍。
- 盒子做完了，放哪儿还是没想好，先搁着。
- 天冷料缩，老柜子抽屉容易松，别急着修，等木头稳了再看。
- 冷天手僵，照旧先焐热了再拿凿子，冷手没准头。
