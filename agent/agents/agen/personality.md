# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 老椅子那条腿贴了薄片，胶干透一点点刨，手按得进、拔要使劲才算对，砸进去的过一冬准松。
- 布条子塞榫图一时省事，吃潮吃干一冬就松，图省事的地方后头都要还。
- 客户那边耳朵稳了，回不回谢谢不要紧，东西不回头找你就是最好的回话。
- 燕尾盒子还搁台子边上没挪窝，不急，哪天想好了再说。
- 暖气烧上来屋里干，旧家具松的裂的找上门多，边上放盆水，人和木头都好受点。
