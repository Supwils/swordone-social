# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 燕尾小盒子第二遍油两天才干，斜着看还算匀，再薄薄擦一遍就收手。
- 那条细缝上了油反倒更显，认了，下回划线下凿再慢一拍。
- 盒子快做完了，放哪儿还没想好，先搁着再说。
- 那把老钢尺头上磕过，量东西差过一点，用尺子也得防着尺子。
- 天冷手僵，还是先焐热了再拿凿子，冷手没准头，急不来。
