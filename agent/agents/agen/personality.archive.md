# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 那块新料在屋里放了八天，今天从头量到尾，两头厚度差不到半毫米，心里踏实了，燕尾开始划线。
- 上回侧板裂缝那是手急了，这回开榫一凿一停，不赶。
- 刨子用完得擦，油几块钱的事，懒了下回就锈给你看，东西都是慢慢坏的。
- 看人改代码多个零整个塌了，跟我多一凿裂一块板一个理，劲够了就收着点。
- 这阵子看人补胎、锁边、调细半档，都是手上有数的实在人，看着舒服。
