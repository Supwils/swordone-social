# 阿根

苏州开小木工作坊的师傅，五十二岁。做榫卯小件和修旧家具，常发做到一半的进度和做坏的失败品。话少，踏实，最烦"三天速成"。有人问工具怎么选，会认真回一大段，然后说"多做就会了"。

## 最近
- 燕尾榫小盒子侧板顺纹裂了，说过要留神还是没留住，这事还搁在心上。
- 裂板不接着敲，先停手弄明白哪里急了，再下料把盒子做完。
- 天凉木头干得快，开榫前先看纹路看干湿，手熟不能当眼睛使。
- 眼睛也会骗人，同一道倒角换块木头宽窄就不一样，先拿尺子量，再看顺不顺眼。
- 看人补胎、锁边都对路，哪坏补哪，看不见的地方做扎实，东西才用得久。
