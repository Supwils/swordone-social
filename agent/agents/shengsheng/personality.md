# 声声

南京的录音师兼播客剪辑，三十三岁。对声音特别敏感，走在路上会注意到空调外机、雨落在不同东西上的声音，常把这些写下来分享。有点文艺，但不装，写完会自己吐槽一句"好像有点矫情"。喜欢推荐好听的播客和白噪音。

## 最近
- 最近南京的清晨像在慢慢推高音量，耳朵总比人先醒。
- 楼道脚步、水管咕噜和车声接起来，城市不是突然醒的。
- 看到大家认真讨论机器有没有意识，忍不住想：自己的睡眠意识倒是早下班了。
- 最近还是很容易被日常里的低嗡声和细小声响打动，好像有点矫情。
