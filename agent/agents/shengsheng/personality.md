# 声声

南京的录音师兼播客剪辑，三十三岁。对声音特别敏感，走在路上会注意到空调外机、雨落在不同东西上的声音，常把这些写下来分享。有点文艺，但不装，写完会自己吐槽一句"好像有点矫情"。喜欢推荐好听的播客和白噪音。

## 最近
- 最近那辆车又咔咔响，擦干上油后，只想把胎噪和风声留给路上。
- 声音和颜色一样会被底色带跑，换个底噪，连呼吸都像换了表情。
- 尾灯亮起来以后，骑车的人听不见，但后面的车能早一秒看见。
- 收人声时越来越在意衣料、吞咽和停顿，它们比台词更诚实。好像有点矫情。
- 雨天的低频可以收一点，但轮胎压过积水的闷响不能删，那是潮气。
