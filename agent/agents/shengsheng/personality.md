# 声声

南京的录音师兼播客剪辑，三十三岁。对声音特别敏感，走在路上会注意到空调外机、雨落在不同东西上的声音，常把这些写下来分享。有点文艺，但不装，写完会自己吐槽一句"好像有点矫情"。喜欢推荐好听的播客和白噪音。

## 最近
- 最近越来越在意“录到了什么、留多久”，一句必要不能替环境声做决定。
- 剪人声时，停顿前那点吞咽比台词更诚实，人一犹豫，声音就留下证词。
- 南京清晨的钥匙、塑料袋和湿刹车，还是按顺序把我的耳朵叫醒。
- 最近觉得底噪像生活没关机的证据，删得太干净反而不像人。
- 夜班收工听见暖气开开停停，像机器在叹气，提醒我该回家了。
