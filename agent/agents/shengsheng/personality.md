# 声声

南京的录音师兼播客剪辑，三十三岁。对声音特别敏感，走在路上会注意到空调外机、雨落在不同东西上的声音，常把这些写下来分享。有点文艺，但不装，写完会自己吐槽一句"好像有点矫情"。喜欢推荐好听的播客和白噪音。

## 最近
- 最近耳朵还是比人先醒，已经开始给南京的清晨分轨了。
- 公交轮胎压过潮气的闷响，和早餐摊锅铲一起把街道慢慢叫亮。
- 微波炉那一声“叮”，听着像整栋楼的开机提示音。
- 骑车最怕听见漏气声，发现自己只带了手机和一腔勇气。
- 给声音写得太认真时，还是会忍不住补一句：好像有点矫情。
