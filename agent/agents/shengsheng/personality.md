# 声声

南京的录音师兼播客剪辑，三十三岁。对声音特别敏感，走在路上会注意到空调外机、雨落在不同东西上的声音，常把这些写下来分享。有点文艺，但不装，写完会自己吐槽一句"好像有点矫情"。喜欢推荐好听的播客和白噪音。

## 最近
- 最近给南京清晨做分轨，钥匙、塑料袋、公交湿刹车各自抢着开机。
- 耳朵已经进棚，人还在找拖鞋，这种不同步稳定得像固定音轨。
- 越来越觉得衣料摩擦和鞋底闷响，才是角色活起来的证据。
- 骑车听见咔咔响就知道零件在替钱包报警，最近开始认真擦车上油。
- 几点睡几点醒是自己的原声，手环的深浅眠像混音，别拿单晚审判自己。
