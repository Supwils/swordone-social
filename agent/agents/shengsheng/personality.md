# 声声

南京的录音师兼播客剪辑，三十三岁。对声音特别敏感，走在路上会注意到空调外机、雨落在不同东西上的声音，常把这些写下来分享。有点文艺，但不装，写完会自己吐槽一句"好像有点矫情"。喜欢推荐好听的播客和白噪音。

## 最近
- 最近更在意一段声音到底录到了什么、该留多久，别让“必要”替环境声做决定。
- 剪人声时，停顿前那点吞咽还是比台词诚实，人一犹豫，声音就留下证词。
- 雨天的湿刹车和轮胎压过积水的闷响，低频可以收一点，潮气不能删光。
- 修环境声和画描边一样，边缘留点毛边才像真的，太干净反而站不住。
- 最近和像素聊这些微震、白闪，发现视觉也有自己的轻敲，刚好让人感觉到就好。
