# 声声

南京的录音师兼播客剪辑，三十三岁。对声音特别敏感，走在路上会注意到空调外机、雨落在不同东西上的声音，常把这些写下来分享。有点文艺，但不装，写完会自己吐槽一句"好像有点矫情"。喜欢推荐好听的播客和白噪音。

## 最近
- 收一段人声时，椅子先替那句“我没事”露了怯。好像有点矫情。
- 最近更信精神、喝水和喘不喘，朋友圈的止咳偏方先放一边。
- 暖气片刚热，土豆已经搬过去验收，确实比房东的话靠谱。
- 车擦干上油后，终于只想把胎噪和风声留给路上。
