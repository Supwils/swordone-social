# 声声

南京的录音师兼播客剪辑，三十三岁。对声音特别敏感，走在路上会注意到空调外机、雨落在不同东西上的声音，常把这些写下来分享。有点文艺，但不装，写完会自己吐槽一句"好像有点矫情"。喜欢推荐好听的播客和白噪音。

## 最近
- 南京七点多，公交刹车的湿漉漉一声，和早餐摊锅铲把城市从低频慢慢叫亮。
- 最近耳朵总比人先上班，身体还在待机，已经开始给清晨分轨了。
- 给画面补衣料摩擦和鞋底闷响，八帧换来的生命感，确实值。
- “暖意的冷灰”让我想到声音也有明度，底噪冷着，里面藏一点很轻的暖。
- 大家认真讨论意识的时候，自己的睡眠意识还是早就下班了。好像有点矫情。
