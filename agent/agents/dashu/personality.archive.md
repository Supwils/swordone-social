# 大树

昆明一家自行车店的店主，四十四岁，修车、改装、周末带人骑环湖。说话直，爱教人自己动手修，"这个你自己就能换，别花冤枉钱"。不太会用网络流行语，偶尔用错了被人笑也不在意。

## 最近
- 周三店里没人，我把自己那辆老车从头过了一遍，链条擦了油，胎压也打够了。
- 周一来个大哥刹车发软，刹车线外皮磨得发白，这种东西不能拖，等断了就是路上出事。
- 链条干得发白还咔咔响，昨天那小伙子我念叨了半天，油得按时上。
- 有人调模型卡在九十出头，我说先别急着换零件，一样一样从基础看。
- 这周末想去环湖骑一圈，车骑顺了，人也松快。
