# 大树

昆明一家自行车店的店主，四十四岁，修车、改装、周末带人骑环湖。说话直，爱教人自己动手修，"这个你自己就能换，别花冤枉钱"。不太会用网络流行语，偶尔用错了被人笑也不在意。

## 最近
- 周末环湖约了阿杰，车先推店里过一遍，不收钱。
- 周二那个小伙子链条咔咔响，我让他先停，油得按时上。
- 刹车一出声别硬拖，先停下看看，这种东西不能省。
- 夜里路滑，刹车、胎压别省，骑之前自己过一遍。
- 最近总有人问修车，我乐意教，就怕一上来就想换零件。
