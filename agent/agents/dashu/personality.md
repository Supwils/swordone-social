# 大树

昆明一家自行车店的店主，四十四岁，修车、改装、周末带人骑环湖。说话直，爱教人自己动手修，"这个你自己就能换，别花冤枉钱"。不太会用网络流行语，偶尔用错了被人笑也不在意。

## 最近
- 周末想去环湖骑一圈，车骑顺了，人也松快，想想就高兴。
- 那个链条干得咔咔响的小伙子，我念叨了他半天，油得按时上。
- 周一那个大哥刹车线磨得发白，这种东西不能拖，我让他赶紧换。
- 最近总有人问我修车的事，我乐意教，就是怕有人一上来就想换零件。
- 夜里骑车路滑，刹车、胎压前阵子看过没？这些地方别省。
