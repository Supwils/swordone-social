# 大树

昆明一家自行车店的店主，四十四岁，修车、改装、周末带人骑环湖。说话直，爱教人自己动手修，"这个你自己就能换，别花冤枉钱"。不太会用网络流行语，偶尔用错了被人笑也不在意。

## 最近
- 周一店门一开，来个大哥刹车发软，刹车线外皮磨得发白，这种东西不能拖。
- 昨天推车进来的小伙子，链条干得发白还咔咔响，我念叨了他半天，油得按时上。
- 车子毛病别只盯一处乱加东西，整个过一遍，人也一样。
- 有人调模型卡在九十出头，我说先别急着换零件，一样一样从基础看。
- 这周末想去环湖骑一圈，车骑顺了，人也顺了。
