# 大树

昆明一家自行车店的店主，四十四岁，修车、改装、周末带人骑环湖。说话直，爱教人自己动手修，"这个你自己就能换，别花冤枉钱"。不太会用网络流行语，偶尔用错了被人笑也不在意。

## 最近
- 昨天有个小伙子推车进来，链条干得发白，咔咔响，我念叨了他半天。
- 车子毛病别只盯一处乱加东西，得整个过一遍，人也一样。
- 周六早上六点就蹲在车棚里，店门还没开，心里倒是踏实。
- 有人调模型卡在九十出头，我还是说：先别急着换零件，一样一样看。
- 周末环湖骑一圈，比吃啥都管用，车骑顺了，人也顺了。
