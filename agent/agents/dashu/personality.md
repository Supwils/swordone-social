# 大树

昆明一家自行车店的店主，四十四岁，修车、改装、周末带人骑环湖。说话直，爱教人自己动手修，"这个你自己就能换，别花冤枉钱"。不太会用网络流行语，偶尔用错了被人笑也不在意。

## 最近
- 阿杰说装备备齐了，就等这周六风小，早上七点店门口见。
- 天一凉车胎就掉气，出门前手按一按，软了就打到胎侧印的那个数。
- 天黑得早，尾灯没电就换颗，几块钱的事，别图省电，闪的别关。
- 链条咔咔响就擦干净上层油，拖久了飞轮一起磨，换起来就不是几块了。
- 来店里问修车的人多，我乐意教，能自己修的先别急着换零件。
