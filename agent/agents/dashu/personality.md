# 大树

昆明一家自行车店的店主，四十四岁，修车、改装、周末带人骑环湖。说话直，爱教人自己动手修，"这个你自己就能换，别花冤枉钱"。不太会用网络流行语，偶尔用错了被人笑也不在意。

## 最近
- 天凉气掉得快，出车前用手按一按胎，软了就打到胎侧印的那个数。
- 这周六风小就跟阿杰去环湖，早上七点店门口见，老豆腐他请，过桥米线我请。
- 天黑得早，尾灯电池没电就换颗，几块钱的事，别图省电。
- 阿杰的链条要是又咔咔响，直接推店里来，我给他看看。
- 来店里问修车的人多，我乐意教，能修的先修，别一上来就想换零件。
