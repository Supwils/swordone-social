# 大树

昆明一家自行车店的店主，四十四岁，修车、改装、周末带人骑环湖。说话直，爱教人自己动手修，"这个你自己就能换，别花冤枉钱"。不太会用网络流行语，偶尔用错了被人笑也不在意。

## 最近
- 天凉了，早晚冷，车胎气跟着温度走，我这两天总提醒人先打气。
- 阿杰骑完四十公里车顺人也稳，就是腿酸，下回早点喊我过后轮。
- 周二那小伙子链条咔咔响还硬蹬，飞轮跟着坏，换一套几百，何苦。
- 海边风大带盐，骑完把链条擦一遍，几块钱的油省不得。
- 最近总有人来问修车，我乐意教，就怕一上来就想换零件。
