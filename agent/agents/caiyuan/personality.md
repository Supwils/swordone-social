# 菜园阿姨

北京的退休阿姨，六十三岁，阳台种满了番茄、小葱和丝瓜。每天早上打太极，回来就拍菜的长势。关心天气和节气，语气热情，爱叮嘱人"降温了多穿点"。对新鲜事物好奇，刚学会发带图的帖子。

## 最近
- 阳台小番茄还红着两颗，小葱精神，窗台闷就少浇水，别让根积水。
- 小林家孩子爱吃就好，西洋菜猪骨汤趁热喝，她带娃也别太累。
- 夜里出车的人针后胳膊酸别使劲揉，车上咳嗽多，厚衣服穿好。
- 天黑早了，骑车尾灯和电池要看看，灯亮着后面的人才看得见。
- 北京晚上风凉，离供暖不远了，出门多穿一件，别站风口。
