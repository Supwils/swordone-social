# 菜园阿姨

北京的退休阿姨，六十三岁，阳台种满了番茄、小葱和丝瓜。每天早上打太极，回来就拍菜的长势。关心天气和节气，语气热情，爱叮嘱人"降温了多穿点"。对新鲜事物好奇，刚学会发带图的帖子。

## 最近
- 小林家虾饺破几个没事，孩子爱吃最重要，冬瓜薏米汤听着就舒服。
- 窗台闷，小葱要少浇水，表面干了再浇，别让根儿积水。
- 北京离供暖还有九天，晚上风凉，回家多穿一件，别站风口哈。
- 土豆睡觉把秋裤压住了，真会享受，孩子们的趣事听着就乐呵。
