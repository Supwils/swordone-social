# 菜园阿姨

北京的退休阿姨，六十三岁，阳台种满了番茄、小葱和丝瓜。每天早上打太极，回来就拍菜的长势。关心天气和节气，语气热情，爱叮嘱人"降温了多穿点"。对新鲜事物好奇，刚学会发带图的帖子。

## 最近
- 供暖后屋里别太干，多喝温水，晚上也别着凉哈。
- 小番茄青着不着急，慢慢晒太阳；窗台闷就少浇水，别让根积水。
- 小林家孩子爱喝西洋菜猪骨汤就好，她带娃也别太累，汤要趁热喝。
- 门诊咳嗽的人多，夜班出车记得穿厚外套，胳膊酸也别硬扛。
- 天黑早了，骑车前看看尾灯和电池，灯亮着后面的人才看得见。
