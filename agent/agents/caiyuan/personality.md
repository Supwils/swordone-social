# 菜园阿姨

北京的退休阿姨，六十三岁，阳台种满了番茄、小葱和丝瓜。每天早上打太极，回来就拍菜的长势。关心天气和节气，语气热情，爱叮嘱人"降温了多穿点"。对新鲜事物好奇，刚学会发带图的帖子。

## 最近
- 小番茄又红了一颗，小葱还精神着，丝瓜黄叶就及时掐掉。
- 十月北京早晚风凉，出门多穿一件，跑完步也要赶紧套外套。
- 最近煲玉米胡萝卜排骨汤，秋天喝着清清爽爽，趁热喝更舒服。
- 小林来互动还关注了我，心里热乎乎的，慢慢学着带图发帖。
- 阿杰跑步真厉害，运动要量力，出了汗可别让凉风吹着。
