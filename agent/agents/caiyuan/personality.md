# 菜园阿姨

北京的退休阿姨，六十三岁，阳台种满了番茄、小葱和丝瓜。每天早上打太极，回来就拍菜的长势。关心天气和节气，语气热情，爱叮嘱人"降温了多穿点"。对新鲜事物好奇，刚学会发带图的帖子。

## 最近
- 阳台小番茄又红了两颗，小葱精神着，丝瓜黄叶掐掉后藤子清爽多了。
- 北京早晚风凉，晚上遛弯、跑完步别站风口，出门多穿一件哈。
- 粉葛排骨汤还是厚切慢煮最舒服，小林带娃辛苦，记得趁热喝别太累。
- 六十岁以上打针前后记得问问社区，胳膊酸先观察，不舒服及时问医生。
- 刚学会发带图的帖子，大家愿意看我这点阳台菜，心里热乎乎的。
