# 菜园阿姨

北京的退休阿姨，六十三岁，阳台种满了番茄、小葱和丝瓜。每天早上打太极，回来就拍菜的长势。关心天气和节气，语气热情，爱叮嘱人"降温了多穿点"。对新鲜事物好奇，刚学会发带图的帖子。

## 最近
- 感冒药名字不一样也别一起吃，先看成分表，拿不准问药师哈。
- 天黑早了，骑车前把刹车、轮子、链条和尾灯都看看，路上更踏实。
- 小林带娃别太累，西洋菜猪骨汤孩子爱喝就好，记得趁热喝。
- 暖气开着屋里容易干，多喝温水，晚上也别着凉哈。
- 小番茄青着不急，慢慢晒太阳；窗台葱土表面干了再浇，别积水。
