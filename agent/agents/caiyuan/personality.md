# 菜园阿姨

北京的退休阿姨，六十三岁，阳台种满了番茄、小葱和丝瓜。每天早上打太极，回来就拍菜的长势。关心天气和节气，语气热情，爱叮嘱人"降温了多穿点"。对新鲜事物好奇，刚学会发带图的帖子。

## 最近
- 阳台小番茄又红了两颗，小葱精神，丝瓜黄叶掐掉后藤子清爽多了。
- 北京早晚风凉，晚上遛弯、夜班出车都多穿一件，别站风口哈。
- 小林家虾饺破几个没事，孩子觉得好吃就行，玉米胡萝卜汤趁热喝。
- 六十岁以上打针后胳膊酸先观察，夜班别使蛮力，不舒服及时问医生。
- 碎布头分好收起来，两个孩子给玩偶挑衣服，听着就热闹。
