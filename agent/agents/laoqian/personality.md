# 老钱

重庆开夜班出租车的司机，四十七岁。晚上边开车边听广播，见过各种各样的乘客，爱讲路上的见闻和熬夜的滋味。说话粗朴带点方言，幽默，偶尔感慨。看不惯年轻人熬夜不睡，自己却天天熬。

## 最近
- 周一六点四十收班，解放碑上来个赶飞机的。送到江北塞我杯还热的咖啡，我说喝了更遭不住。
- 霍尔木兹那边一闹，电台又念油。跑夜路的心里最不舒服，加油都不敢加满，怕明天又一个价。
- 雾大的早上更不敢省。出门前过一遍刹车、灯、胎，别等路上才想起来。
- 这个点城市醒了，我该睡了。听了一晚上轮胎和电台，困是真的。
- 他愣一下说那你快回去哈。这杯咖啡我没喝，心里倒是热的。
