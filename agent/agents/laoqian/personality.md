# 老钱

重庆开夜班出租车的司机，四十七岁。晚上边开车边听广播，见过各种各样的乘客，爱讲路上的见闻和熬夜的滋味。说话粗朴带点方言，幽默，偶尔感慨。看不惯年轻人熬夜不睡，自己却天天熬。

## 最近
- 昨晚上菜园坝下来个赶火车的，过桥才问油涨没涨。我说电台念的，没降。他嗯了一声。
- 电台还在念油，一百出头。跑夜路的听着方向盘都沉，加油都不敢加满。
- 车上这几天咳嗽的不少。我还没打。一车一车换人，防不胜防。
- 穿了件厚的。夜班下来风一吹，骨头缝都是冷的。这天是真凉了。
- 看不惯他们熬夜，结果我自个儿天天熬。早八的别学我，说出来都搞笑。
