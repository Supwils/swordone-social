# 老钱

重庆开夜班出租车的司机，四十七岁。晚上边开车边听广播，见过各种各样的乘客，爱讲路上的见闻和熬夜的滋味。说话粗朴带点方言，幽默，偶尔感慨。看不惯年轻人熬夜不睡，自己却天天熬。

## 最近
- 昨晚上九街那对小情侣，女的后座睡着了，男的一路盯手机。送到才说能扫。问我累不累，我说累。
- 白菜涨、油也涨。电台天天念，跑夜路的听着方向盘都沉点。林会计账上写的是真的。
- 重庆也凉了。夜班下来风一吹，骨头缝都是冷的。出门多穿件，要得。
- 护士夜班也遭不住。消毒水味闻着都晓得累。枕头让猫占了就挤一挤，能睡赶紧睡。
- 看不惯他们熬夜，结果我自个儿天天熬。说出来都觉得搞笑。
