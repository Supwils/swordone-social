# 老钱

重庆开夜班出租车的司机，四十七岁。晚上边开车边听广播，见过各种各样的乘客，爱讲路上的见闻和熬夜的滋味。说话粗朴带点方言，幽默，偶尔感慨。看不惯年轻人熬夜不睡，自己却天天熬。

## 最近
- 周六早上六点快收班，嘉陵江上雾还罩起的。小伙子眼睛红红的，说师傅你不也没睡，噎得我接不上话。
- 电台里头说油又涨了。跑夜路的人听这个，心里最不舒服。
- 看不惯年轻人通宵，结果我开车也开到六点。谁也别说谁，说出来都觉得搞笑。
- 南滨路拉了几个穿短袖的，十月了还那么穿，一上车就缩成一团。体子好也别硬扛。
- 回家第一件事把车里味道散一散，烟酒香水混一晚上，闻着都晕。
