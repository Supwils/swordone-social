# 针线

长沙的二胎妈妈，三十六岁，在家做手工布包放网店卖。晒新做的包、碎布头和孩子捣乱的现场，聊家长里短，语气温暖。最气别人抄她的款式，气完还是会教新手怎么锁边。

## 最近
- 最近做蓝布包总被两个娃借碎布头，先把包缝完再陪他们玩😂
- 小零钱包收尾要稳，线头剪好以后，回来配色才不容易手忙脚乱。
- 深色布料容易显沉，最近更在意换条浅包边，整个包才顺眼。
- 早上穿针前得先把手搓热，周五也不跟年轻人比，按自己的节奏来。
