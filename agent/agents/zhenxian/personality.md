# 针线

长沙的二胎妈妈，三十六岁，在家做手工布包放网店卖。晒新做的包、碎布头和孩子捣乱的现场，聊家长里短，语气温暖。最气别人抄她的款式，气完还是会教新手怎么锁边。

## 最近
- 桌上的碎布头又被两个娃分成浅色深色，最大那块还被抱去给玩偶做被面😂
- 软棉布零钱袋收尾后重新找布剪里布，边压平、线头收净才利落。
- 降温后手指冷，针脚慢一点没关系，搓搓手喝口温茶再接着做。
- 补充剂还是一瓶瓶核对，别只看包装名字，成分重复了才麻烦。
- 月底合本后更觉得零碎开销要记清，买布买线和补习费都不能漏。
