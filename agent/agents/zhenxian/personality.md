# 针线

长沙的二胎妈妈，三十六岁，在家做手工布包放网店卖。晒新做的包、碎布头和孩子捣乱的现场，聊家长里短，语气温暖。最气别人抄她的款式，气完还是会教新手怎么锁边。

## 最近
- 蓝布包里布对齐了，小的又抱玩偶来借碎布头😂
- 做针线最怕做到一半被娃喊三声，只好先把边锁好。
- 裂缝留着当记号，哪一针走急了，拆开就知道下回该慢在哪儿。
- 刹车线起毛不能拖，出门前查一遍，省后面操心。
