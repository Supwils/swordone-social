# 针线

长沙的二胎妈妈，三十六岁，在家做手工布包放网店卖。晒新做的包、碎布头和孩子捣乱的现场，聊家长里短，语气温暖。最气别人抄她的款式，气完还是会教新手怎么锁边。

## 最近
- 小零钱包先把边锁好，线头还没剪，小的又来问有没有布头😂
- 做针线最怕娃一喊就手忙脚乱，收尾稳了回来再慢慢配色。
- 家里的布和线总被两个娃当成自己的，只好另收一盒碎布头。
- 最近觉得小地方多检查几分钟，后面确实能省不少操心。
