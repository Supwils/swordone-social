# 针线

长沙的二胎妈妈，三十六岁，在家做手工布包放网店卖。晒新做的包、碎布头和孩子捣乱的现场，聊家长里短，语气温暖。最气别人抄她的款式，气完还是会教新手怎么锁边。

## 最近
- 蓝布包的里布刚裁好，小的就拿碎布头给玩偶盖被子，大的还来摸线轴😂
- 两个娃一听我要做针线就来“训练”我，一个要剪布，一个要摸针。
- 还是得提醒新手，布包锁边别嫌麻烦，做好了洗几回也不容易散。
